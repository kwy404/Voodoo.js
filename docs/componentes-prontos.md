# Ready-made components

The complete build registers 29 components. All are used by writing HTML only, without a line of
JavaScript, and each accepts both spellings: `<VButton>` and `<v-button>`.

```html
<script src="https://cdn.jsdelivr.net/npm/voodoojs/dist/voodoo.full.min.js" defer></script>

<VButton variant="primary" size="lg" icon="check">Salvar</VButton>
<VCard title="Faturamento"><p>Conteúdo</p></VCard>
<VInput label="E-mail" type="email" hint="Nunca compartilhamos" v-model="email" />
<VBadge tone="success">Ativo</VBadge>
```

## Rules that apply to all

**No color is hardcoded in CSS.** Everything comes from variables generated by `V.palette()`, so changing the
palette changes the entire interface instantly in both themes. See [Theme and palette](tema-e-paleta.md).

**Boolean props accept three forms.** The empty attribute (`loading`), the text form (`loading="true"`)
and reactive binding (`:loading="salvando"`). Values accepted as true: empty attribute,
`true`, `1`, `sim`, `yes`.

**Lists accept three formats.** A variable name from the surrounding scope, a comma-separated literal list,
or reactive binding:

```html
<VSelect options="estados" />          <!-- variable from surrounding v-data -->
<VSelect options="SP, RJ, MG" />       <!-- literal list -->
<VSelect :options="listaCarregada" />  <!-- reactive binding -->
```

**Form controls are drawn from scratch.** Each uses `appearance: none` and keeps a hidden native
element, which maintains accessibility and form submission. They work with `v-model` on the component itself.

**Icons** come from an internal SVG set. Available names:

```
check  x  plus  minus  search  chevron-down  chevron-up  chevron-left  chevron-right
arrow-up  arrow-down  arrow-left  arrow-right  user  users  mail  lock  eye  eye-off
calendar  clock  star  info  alert  warning  trash  edit  copy  download  upload
settings  home  heart  bell  filter  external  refresh  folder  file  image  link
menu  more  logout  card  chart  box  inbox
```

An unknown name simply draws nothing.

## Action

### VButton

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `primary`, `secondary`, `outline`, `ghost`, `soft`, `link`, `danger`, `success`, `warning`, `accent` | `primary` |
| `size` | `xs`, `sm`, `md`, `lg`, `xl` | `md` |
| `icon` | icon name on the left | empty |
| `iconRight` | icon name on the right | empty |
| `type` | `button`, `submit`, `reset` | `button` |
| `loading` | boolean | `false` |
| `disabled` | boolean | `false` |
| `block` | takes full width | `false` |
| `rounded` | fully rounded corners | `false` |
| `ariaLabel` | accessible label | empty |

```html
<VButton variant="primary" icon="check">Confirmar</VButton>
<VButton variant="danger" size="sm" icon="trash">Excluir</VButton>
<VButton :loading="salvando" block>Salvar tudo</VButton>
<VButton variant="ghost" iconRight="external">Abrir</VButton>
```

### VIconButton

Icon-only button. The `label` becomes the accessible label.

| Prop | Default |
| --- | --- |
| `icon` | `more` |
| `label` | empty |
| `variant` | `ghost` |
| `size` | `md` |
| `type` | `button` |
| `disabled`, `loading`, `rounded` | `false` |

```html

```

### VTooltipButton

Button with tooltip on mouse hover or focus.

| Prop | Default |
| --- | --- |
| `tooltip` | empty |
| `placement` | `top` (accepts `top`, `bottom`, `left`, `right`) |
| `variant` | `ghost` |
| `size` | `md` |
| `icon`, `ariaLabel` | empty |
| `type` | `button` |
| `disabled` | `false` |

```html

```

### VSelect

Custom-drawn select with search, multi-select, and keyboard navigation.

| Prop | Default |
| --- | --- |
| `label`, `hint`, `error`, `name`, `id` | empty |
| `placeholder` | `Select` |
| `searchPlaceholder` | `Search...` |
| `emptyText` | `No options found` |
| `options` | list of options |
| `value` | initial value |
| `size` | `md` |
| `multiple`, `searchable`, `clearable`, `disabled`, `required` | `false` |

Emits `change` with the current value (text, or array when `multiple`).

Formats accepted in `options`:

```js
['SP', 'RJ', 'MG']
[{ value: 'sp', label: 'São Paulo' }, { value: 'rj', label: 'Rio de Janeiro', disabled: true }]
```

Alternative keys `id`, `key`, `text`, `name`, and `title` are also understood.

```html
<div v-data="{ estados: [{ value: 'sp', label: 'São Paulo' }], uf: '' }">
  <VSelect label="Estado" options="estados" searchable clearable v-model="uf" />
</div>
```

## Data and navigation

### VTable

| Prop | Default |
| --- | --- |
| `columns` | column definition |
| `rows` | array of objects |
| `empty` | `No records found` |
| `sortable` | `true` |
| `hover` | `true` |
| `dense`, `striped` | `false` |
| `caption` | empty |

Emits `sort` with `{ key, direction }`.

Columns accept three formats:

```js
['nome', 'email']                                   // label derived from key
[{ key: 'nome', label: 'Nome', align: 'left', sortable: true }]
```

```html
<VTable columns="nome:Nome, total:Total:right" :rows="pedidos" striped />
```

In text form, each column is `key:label:alignment`. Keys with dots work:
`cliente.nome`.

## Using with forms

Field components work with `v-model` on the component itself and also within a
`<form v-submit>`, because each maintains a hidden native control with the declared `name`:

```html
<form v-submit="/api/inscricoes" v-validate v-toast-success="Inscrição enviada!">
  <VInput label="Nome" name="nome" required />
  <VInput label="E-mail" name="email" type="email" required />
  <VSelect label="Plano" name="plano" options="Mensal, Anual" required />
  <VCheckbox name="termos" label="Aceito os termos" required />
  <VButton type="submit" :loading="$form.loading">Enviar</VButton>
</form>
```
