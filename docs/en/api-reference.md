# API Reference

Every symbol on the `V` object, grouped by purpose. Generated by reading
`packages/voodoojs/src/core.ts`, `index.ts`, `essential.ts` and `minimo.ts`.

**Stability tiers** follow [CONVENTIONS.md](../../CONVENTIONS.md):

| Tier            | Meaning |
| --------------- | ------- |
| `stable`        | Covered by SemVer once 1.0 ships |
| `experimental`  | Usable and documented; the shape may still change |
| `internal`      | Exists for the runtime, the devtools or tests. Not a contract. |

While the version is `0.x`, minor releases may still break `stable` symbols. Tagging every
symbol individually is tracked in [ROADMAP.md](../../ROADMAP.md); this page reflects the
intent.

**Build** column: `core` = in every build, `essential` = in `voodoo.min.js` and above,
`full` = only in `voodoo.full.min.js` or a bundler import.

## The `V` object itself

`V` is both a function and an object.

```js
V('#list .item')       // chainable collection
V.toast.success('Hi')  // service
```

| `V(selector, context?)` | `=> VoodooCollection` | stable | core |
| `V.version` | `string` | stable | core |
| `V.config` | `VoodooConfig` | stable | core |

## Utilities

Spread onto `V` from `voodoojs/utils`, and importable on their own. All `stable`, all in
every build.

**Identifiers and timing**
`uuid()` `uid(prefix?)` `sleep(ms)` `parseDuration(value, fallback?)`
`debounce(fn, wait?)` `throttle(fn, wait?)` `memoize(fn, keyFn?)`

**Collections and objects**
`clone(value)` `merge(target, ...sources)` `groupBy(list, key)` `unique(list, key?)`
`chunk(list, size?)` `sortBy(list, key, dir?)` `get(object, path, fallback?)`
`set(object, path, value)` `random(min?, max?)` `sample(list)`

**Strings**
`slugify(text, separator?)` `truncate(text, length?, suffix?)` `capitalize(text)`
`titleCase(text)` `escapeHtml(text)` `stripTags(html)`

**Formatting**
`setFormatDefaults(locale?, currency?)` `formatCurrency(value, options?)`
`formatNumber(value, options?)` `formatDate(value, pattern?)` `relativeTime(value, locale?)`
`formatFileSize(bytes, decimals?)` `formatPercent(value, decimals?, locale?)`

**Environment**
`isBrowser` `device`

> The `once(fn)` wrapper is exported from `voodoojs/utils` but is **not** reachable as
> `V.once`, which is the event bus method.
>
> `escapeHtml` and `stripTags` are formatting helpers, not sanitizers. See
> [Security](security.md).

`relativeTime` uses `Intl.RelativeTimeFormat`, which needs Safari 14 or later. See
[BROWSER_SUPPORT.md](../../BROWSER_SUPPORT.md).
