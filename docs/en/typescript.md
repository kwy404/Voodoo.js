# TypeScript

Voodoo.js is written in TypeScript with `strict: true` and ships generated `.d.ts` files for
every module entry. No `@types` package is needed.

---

## Installation

```bash
npm install voodoojs
```

```ts
import V from 'voodoojs';

V.start();
```

Types come from `packages/voodoojs/dist/index.d.ts`, generated by `tsup` with `dts: true`.

---

## Entry points

| Import                  | Contains |
| ----------------------- | -------- |
| `voodoojs`              | The full surface, plus named re-exports |
| `voodoojs/reactivity`   | `reactive`, `ref`, `computed`, `watch`, `effect`, `EffectScope` |
| `voodoojs/http`         | `http`, `request`, `HttpError` and their types |
| `voodoojs/utils`        | The pure helpers |

Each has its own `.d.ts`. The last three pull in no DOM code, so they work in Node, Bun and
Deno.

```ts
import { reactive, computed, type Ref, type ComputedRef } from 'voodoojs/reactivity';
import { http, type HttpResponse, type RequestConfig } from 'voodoojs/http';
import { debounce, formatCurrency } from 'voodoojs/utils';
```

## Reactivity

`reactive` preserves the input type:

```ts
interface User { id: number; name: string; email: string }

const state = V.reactive({
  user: null as User | null,
  items: [] as string[],
  loading: false,
});

state.user?.name;    // string | undefined
state.items.push('a');
```

`ref` and `computed`:

```ts
import type { Ref, ComputedRef } from 'voodoojs';

const count: Ref<number> = V.ref(0);
const double: ComputedRef<number> = V.computed(() => count.value * 2);

count.value++;
double.value;        // number, read-only
```

A writable computed:

```ts
const celsius = V.ref(0);

const fahrenheit = V.computed<number>({
  get: () => celsius.value * 9 / 5 + 32,
  set: (f) => { celsius.value = (f - 32) * 5 / 9; },
});
```

`watch`:

```ts
const stop = V.watch(
  () => state.user,
  (next: User | null, prev: User | null | undefined) => {
    if (next) load(next.id);
  },
  { immediate: true }
);

stop();
```

## Components

```ts
import type { ComponentDefinition } from 'voodoojs';

interface CounterState { count: number }
interface CounterProps { start: number }

const counter: ComponentDefinition = {
  props: {
    start: { type: 'number', default: 0 },
  },

  state: (props): CounterState => ({ count: props.start as number }),

  computed: {
    double(this: CounterState & CounterProps): number {
      return this.count * 2;
    },
  },

  methods: {
    increment(this: CounterState): void {
      this.count++;
    },
  },

  template: `<button @click="increment()">{ count } / { double }</button>`,
};

V.component('counter', counter);
```

`this` inside methods, computed values and hooks is a proxy that merges specials, computed
values, methods, props and state. `ComponentDefinition` types it as `any`, because the merge
is not knowable ahead of time. Annotating `this` yourself, as above, recovers the checking
where it matters.

For stronger typing, describe the instance once:

```ts
interface CounterInstance {
  count: number;
  start: number;
  readonly double: number;
  increment(): void;
  $el: HTMLElement;
  emit(event: string, detail?: unknown): void;
}

V.component('counter', {
  props: { start: { type: 'number', default: 0 } },
  state: (props) => ({ count: props.start }),
  computed: {
    double(this: CounterInstance) { return this.count * 2; },
  },
  methods: {
    increment(this: CounterInstance) {
      this.count++;
      this.emit('changed', this.count);
    },
  },
});
```

## Stores

```ts
interface CartItem { id: number; name: string; price: number; quantity: number }

interface CartStore {
  items: CartItem[];
  add(product: Omit<CartItem, 'quantity'>): void;
  remove(id: number): void;
  total(): number;
}

const cart = V.store<CartStore>('cart', {
  items: [],

  add(product) {
    const existing = this.items.find((i) => i.id === product.id);
    if (existing) existing.quantity++;
    else this.items.push({ ...product, quantity: 1 });
  },

  remove(id) {
    this.items = this.items.filter((i) => i.id !== id);
  },

  total() {
    return this.items.reduce((s, i) => s + i.price * i.quantity, 0);
  },
});

cart.add({ id: 1, name: 'Book', price: 30 });
cart.total();   // number
```

`V.stores` is a proxy typed as `Record<string, Record<string, any>>`, so retrieving a store
from it loses the type. Keep the value returned by `V.store()`, or cast:

```ts
const cart = V.stores.cart as unknown as CartStore;
```

## HTTP

```ts
import type { HttpResponse, RequestConfig, HttpMethod } from 'voodoojs';

interface User { id: number; name: string; email: string }

const users = await V.http.get<User[]>('/api/users');
const user  = await V.http.post<User>('/api/users', { name: 'Ana' });

const response: HttpResponse<User[]> = await V.http.request<User[]>({
  url: '/api/users',
  method: 'GET',
});

response.data;      // User[]
response.status;    // number
```

Typed error handling:

```ts
try {
  await V.http.post<User>('/api/users', payload);
} catch (err) {
  if (err instanceof V.HttpError) {
    const body = err.data as { errors?: Record<string, string> };
    if (body.errors) V.showFormErrors(form, body.errors);
  }
}
```

Typed interceptors:

```ts
V.http.interceptors.request.use((config: RequestConfig): RequestConfig => {
  const token = V.storage.get<string>('token');
  if (token) config.headers = { ...config.headers, Authorization: `Bearer ${token}` };
  return config;
});
```

## Directives

```ts
import type { DirectiveHooks, DirectiveBinding } from 'voodoojs';

const highlight: DirectiveHooks<string> = {
  mounted(el: HTMLElement, binding: DirectiveBinding<string>) {
    el.style.background = binding.value;
  },
  updated(el, binding) {
    el.style.background = binding.value;
  },
};

V.directive('highlight', highlight);
```

`DirectiveBinding<T>` types `value` and `oldValue` as `T`. `scope` is a `Scope`; `instance`
is `any`, because a component instance is dynamic.

## Plugins

```ts
import type { VoodooPlugin } from 'voodoojs';

interface AnalyticsOptions {
  url: string;
  batch?: number;
}

export const analytics: VoodooPlugin = {
  name: 'analytics',

  install(V, options) {
    const config = { batch: 10, ...(options as unknown as AnalyticsOptions) };
    // ...
  },
};
```

`VoodooPlugin.install` is typed `(V: any, options?: Record<string, unknown>) => void`. `V`
is `any` because the object's shape depends on which build is loaded, so cast your options
at the boundary as shown.

To add your own surface to `V` with types, use declaration merging:

```ts
declare module 'voodoojs' {
  interface Voodoo {
    analytics: {
      track(event: string, data?: Record<string, unknown>): void;
      flush(): void;
    };
  }
}
```

## Configuration

```ts
import type { VoodooConfig } from 'voodoojs';

V.config.prefix = 'data-v-';
V.config.autoDiscover = false;
V.config.baseURL = '/api';
V.config.sanitizeUrls = true;
V.config.globals.APP_VERSION = '2.1.0';
```

`V.config` is typed as `VoodooConfig`, so a typo in a field name is a compile error.

## Application mode

```ts
import type { App, AppOptions } from 'voodoojs';

const options: AppOptions = {
  state: () => ({ n: 0 }),
  methods: { add() { this.n++; } },
  template: `<button @click="add()">{ n }</button>`,
};

const app: App = V.createApp(options);
const instance = app.mount('#app');

const root = await app.whenMounted();
```

## CDN with types

If you load Voodoo.js from a CDN but write TypeScript, install the package for its types and
declare the global:

```bash
npm install --save-dev voodoojs
```

```ts
// globals.d.ts
import type V from 'voodoojs';

declare global {
  const V: typeof V;
  interface Window {
    V: typeof V;
    Voodoo: typeof V;
  }
}

export {};
```

## `tsconfig` recommendation

```json
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "lib": ["ES2021", "DOM", "DOM.Iterable"],
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true
  }
}
```

This mirrors `tsconfig.base.json` in the repository. `moduleResolution: "Bundler"` is what
resolves the `voodoojs/reactivity` style subpath exports.

## Where types are deliberately loose

Three places use `any` on purpose, because the value genuinely is not knowable in advance:

- `DirectiveBinding<T = any>` when no type argument is given;
- the component instance proxy, which merges five sources at runtime;
- `VoodooPlugin.install(V: any, ...)`, because the surface depends on the build.

New `any` in a public signature needs a reason. See
[CONVENTIONS.md](../../CONVENTIONS.md) and the *TypeScript* dimension in
[QUALITY.md](../../QUALITY.md).
