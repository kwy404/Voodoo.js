Design System

Voodoo.js Design System

Uma camada de estilo em CSS puro para produtos construidos com Voodoo.js. Zero dependencias, zero build, zero JavaScript obrigatorio. Voce linka quatro arquivos e ja tem tokens, componentes e utilitarios funcionando em tema claro e escuro.

A paleta tem tres escalas de marca, roxo, magenta e tinta, mais tres cores de estado. Os componentes nunca usam a paleta bruta: eles usam as cores semanticas, que sao as unicas que mudam com o tema. Os valores abaixo sao lidos ao vivo do CSS, entao mudam quando voce troca o tema.

Tabs

O estado ativo e lido de aria-selected, nunca de uma classe. As setas do teclado navegam entre as abas.

Instale o pacote com o gerenciador da sua preferencia. Nao ha etapa de build obrigatoria.

Importe o modulo, declare os sinais e monte o componente na raiz da aplicacao.

A API publica tem doze funcoes. Todas retornam objetos imutaveis.

Variante em pilulas, util quando a barra de abas divide espaco com outros controles.

Ambiente de homologacao com dados sinteticos.

Accordion

Construido sobre <details> e <summary>, entao abre, fecha e responde ao teclado sem uma linha de JavaScript.

O design system precisa de build?
Nao. Sao quatro arquivos CSS estaticos. Voce pode servir direto do disco, de um CDN ou colar dentro de uma tag style.
Da para usar so uma parte?
Da. O unico arquivo obrigatorio e tokens.css. Os outros tres dependem dele, mas nao dependem entre si, com a excecao dos utilitarios que precisam vir por ultimo para vencer os componentes.
Como funciona o tema escuro?
O tema escuro redefine apenas as variaveis semanticas. Ele responde a preferencia do sistema e tambem ao atributo data-theme no elemento html, colocado pelo alternador do topo da pagina.
HTML
<div class="v-accordion">
  <details class="v-accordion__item" open>
    <summary class="v-accordion__trigger">Precisa de build?</summary>
    <div class="v-accordion__panel">Nao. Sao quatro arquivos CSS.</div>
  </details>
</div>

Codigo

Codigo em linha para nomes de tokens e funcoes, bloco de codigo para exemplos. O bloco sempre rola dentro de si mesmo, nunca empurra a pagina.

Chame voodoo.cast() depois de registrar os componentes, ou pressione Ctrl + K para abrir a paleta de comandos.

app.js 
import { cast, signal } from "voodoo";

const contador = signal(0);

cast("#app", () => `
  <button class="v-btn v-btn--primary">
    Cliques: ${contador()}
  </button>
`);
