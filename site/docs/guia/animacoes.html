Interface and effects

Animations

An animation engine of its own, written in vanilla JavaScript, with a single requestAnimationFrame loop shared by every active animation. Two ways of advancing: a tween, with a fixed duration and a curve, and a spring, with real numerical integration of stiffness, damping and mass.

voodoo.full.min.js only

The animation module exists only in the full build. In the other two files the v-motion* directives are not recognized and the element stays as it is.

v-motion

Animates the element as soon as it is initialized.

<div>
  <p v-motion="fadeUp">Appears while rising</p>
  <p v-motion="{ opacity: [0, 1], x: [-40, 0], duration: 700 }">With values of your own</p>
  <p v-motion="{ scale: [0.6, 1], spring: { stiffness: 300, damping: 12 } }">With a spring</p>
</div>

Presets

NameWhat it does
fadeInOpacity only
fadeUpRises a few pixels while appearing. The most used one in lists
fadeDownDescends while appearing
scaleInGrows from the inside out, with a slight overshoot at the end
slideLeftSlides in from the right
slideRightSlides in from the left
popBursts in place, with a very lively spring
blurInComes out of a blur until it is sharp
flipTurns on the horizontal axis, like a card flipping over
 
V.animate('.card', V.motion.fadeUp);
V.motion.pop;  // { opacity: [0,1], scale: [0.6,1], spring: { stiffness: 420, damping: 18 } }

Animatable properties

Any numeric CSS property works. On top of those there are shorthands that feed a single transform per element, so several animations live together without overwriting each other: 

x  y  z  scale  scaleX  scaleY  rotate  rotateX  rotateY  skewX  skewY

And filter shorthands:

blur  brightness  contrast  grayscale  saturate

Colours are really interpolated, understanding #fff, #112233aa, rgb(), rgba(), hsl(), hsla() and transparent. A single value uses the current state as its starting point; a pair [from, to] sets both ends.

Options

OptionDefaultWhat it does
duration400Duration in milliseconds. Ignored with a spring
delay0Waits before starting
easingeaseOutThe name of an easing or a function of your own
springtrue for the defaults, or { stiffness, damping, mass, velocity }
repeat0Extra repetitions. 2 runs it three times
repeatTypelooploop, reverse or mirror
forcefalseIgnores prefers-reduced-motion. Save it for essential animations
onUpdateReceives the progress on every frame
onCompleteCalled at the end

Ready-made curves: linear, easeIn, easeOut, easeInOut, easeOutBack, easeOutExpo, anticipate and bounce. They all live in V.easings.

Animating on scroll

<section v-motion-scroll="fadeUp">Animates when it appears</section>
<section v-motion-scroll.repeat="fadeIn">Animates every time it appears</section>
<section v-motion-scroll="scaleIn" v-motion-scroll-amount="0.5">Half of it visible</section>
<section v-motion-scroll="fadeUp" v-motion-scroll-margin="-100px">With a margin</section>

The initial state is applied on mount, so the element is born hidden and does not flash before the scroll reaches it.

Staggering siblings

<ul v-motion-stagger="90">
  <li v-motion="fadeUp">One</li>
  <li v-motion="fadeUp">Two</li>
  <li v-motion="fadeUp">Three</li>
  <li v-motion="fadeUp">Four</li>
</ul>

The value is the interval in milliseconds between one child and the next. v-motion-stagger-from changes where the wave starts, accepting center and last besides the beginning.

Hover and tap

<div class="linha">
  <button v-motion-hover="{ scale: 1.08 }">Hover over me</button>
  <button v-motion-tap="{ scale: 0.94 }">Click and hold</button>
</div>

Both go back to the original state on their own when the mouse leaves or the click ends. Because they write into the same shared transform, they can live on the same element.

Numbers and text

<div>
  <h3 v-count="128400" v-count-duration="1400" v-count-prefix="$ "></h3>
  <p v-typewriter="JavaScript feels like magic." v-typewriter-speed="45"></p>
</div>

v-count animates from zero to the number given, and v-typewriter writes the text letter by letter. Both respect prefers-reduced-motion, and in that case show the final result straight away.

From JavaScript

const control = V.animate('#box', { x: [0, 200], rotate: [0, 180] }, { duration: 600 });
await control.finished;
control.stop();

V.stagger('.card', V.motion.fadeUp, { delay: 70, from: 'center', start: 200 });

V.spring(0, 320, { stiffness: 210, damping: 22, onUpdate: (v) => { bar.style.width = v + 'px' } });

const stop = V.inView(section, (entry) => section.classList.add('active'), { amount: 0.5 });
V.scrollProgress(article, (p) => { bar.style.transform = 'scaleX(' + p + ')' });

The target of V.animate can be an element, a list, a NodeList or a CSS selector. V.spring integrates a spring between two numbers and hands you the value on every frame without touching the DOM, which suits smooth scrolling, counters and any other numeric value.

v-flip and v-parallax

v-flip records the element's position and, when it changes between updates, animates from the old place to the new one: the FLIP technique. It is what makes a reordered list slide instead of jump. Combine it with :key, so that the elements are reused instead of recreated. 

<li v-for="item in sortedItems" :key="item.id" v-flip>{ item.name }</li>
<li v-flip="{ duration: 300, easing: 'easeInOut' }">...</li>

<img v-parallax="0.3" src="/background.jpg" alt="">
<img v-parallax="-0.2" src="/foreground.png" alt="">

v-parallax shifts the element as the page scrolls; negative values reverse the direction. With prefers-reduced-motion, it does nothing.

Reduced motion

Respected by default

Everything here respects prefers-reduced-motion: reduce: in that case the final state is applied at once, with no frames in between. The result is the same, without the movement. Only use force when the animation carries meaning that the final state alone does not convey.
