Interface e efeitos

Animações

Um motor de animação próprio, escrito em vanilla, com um único laço de requestAnimationFrame compartilhado por todas as animações ativas. Dois modos de progresso: tween, com duração fixa e curva, e mola, com integração numérica real de rigidez, atrito e massa.

Só no voodoo.full.min.js

O módulo de animação existe apenas no build completo. Nos outros dois arquivos as directives v-motion* não são reconhecidas e o elemento fica como está.

v-motion

Anima o elemento assim que ele é inicializado.

<div>
  <p v-motion="fadeUp">Aparece subindo</p>
  <p v-motion="{ opacity: [0, 1], x: [-40, 0], duration: 700 }">Com valores próprios</p>
  <p v-motion="{ scale: [0.6, 1], spring: { stiffness: 300, damping: 12 } }">Com mola</p>
</div>

Presets

NomeO que faz
fadeInSó opacidade
fadeUpSobe alguns pixels enquanto aparece. O mais usado em listas
fadeDownDesce enquanto aparece
scaleInCresce de dentro para fora, com um leve exagero no fim
slideLeftEntra deslizando da direita
slideRightEntra deslizando da esquerda
popEstoura no lugar, com mola bem viva
blurInSai do desfoque até ficar nítido
flipGira no eixo horizontal, como uma carta virando
 
V.animate('.card', V.motion.fadeUp);
V.motion.pop;  // { opacity: [0,1], scale: [0.6,1], spring: { stiffness: 420, damping: 18 } }

Propriedades animáveis

Qualquer propriedade CSS numérica funciona. Além delas existem atalhos que alimentam um único transform por elemento, então várias animações convivem sem sobrescrever umas às outras: 

x  y  z  scale  scaleX  scaleY  rotate  rotateX  rotateY  skewX  skewY

E atalhos de filtro:

blur  brightness  contrast  grayscale  saturate

Cores são interpoladas de verdade, entendendo #fff, #112233aa, rgb(), rgba(), hsl(), hsla() e transparent. Um valor único usa o estado atual como ponto de partida; um par [de, para] define os dois extremos.

Opções

OpçãoPadrãoO que faz
duration400Duração em milissegundos. Ignorada com mola
delay0Espera antes de começar
easingeaseOutNome de um easing ou função própria
springtrue para os padrões, ou { stiffness, damping, mass, velocity }
repeat0Repetições extras. 2 executa três vezes
repeatTypelooploop, reverse ou mirror
forcefalseIgnora prefers-reduced-motion. Reserve para animações essenciais
onUpdateRecebe o progresso a cada quadro
onCompleteChamado no fim

Curvas prontas: linear, easeIn, easeOut, easeInOut, easeOutBack, easeOutExpo, anticipate e bounce. Todas estão em V.easings.

Animar na rolagem

<section v-motion-scroll="fadeUp">Anima ao aparecer</section>
<section v-motion-scroll.repeat="fadeIn">Anima toda vez que aparece</section>
<section v-motion-scroll="scaleIn" v-motion-scroll-amount="0.5">Metade visível</section>
<section v-motion-scroll="fadeUp" v-motion-scroll-margin="-100px">Com margem</section>

O estado inicial é aplicado na montagem, então o elemento já nasce escondido e não pisca antes de a rolagem chegar nele.

Onda entre irmãos

<ul v-motion-stagger="90">
  <li v-motion="fadeUp">Um</li>
  <li v-motion="fadeUp">Dois</li>
  <li v-motion="fadeUp">Três</li>
  <li v-motion="fadeUp">Quatro</li>
</ul>

O valor é o intervalo em milissegundos entre um filho e o seguinte. v-motion-stagger-from muda o ponto de partida da onda, aceitando center e last além do começo.

Hover e tap

<div class="linha">
  <button v-motion-hover="{ scale: 1.08 }">Passe o mouse</button>
  <button v-motion-tap="{ scale: 0.94 }">Clique e segure</button>
</div>

Os dois voltam sozinhos ao estado original quando o mouse sai ou o clique termina. Como eles escrevem no mesmo transform compartilhado, podem conviver no mesmo elemento.

Números e texto

<div>
  <h3 v-count="128400" v-count-duration="1400" v-count-prefix="R$ "></h3>
  <p v-typewriter="JavaScript feels like magic." v-typewriter-speed="45"></p>
</div>

v-count anima de zero até o número indicado, e v-typewriter escreve o texto letra por letra. Os dois respeitam prefers-reduced-motion, e nesse caso mostram o resultado final de imediato.

Por JavaScript

const controle = V.animate('#caixa', { x: [0, 200], rotate: [0, 180] }, { duration: 600 });
await controle.finished;
controle.stop();

V.stagger('.card', V.motion.fadeUp, { delay: 70, from: 'center', start: 200 });

V.spring(0, 320, { stiffness: 210, damping: 22, onUpdate: (v) => { barra.style.width = v + 'px' } });

const parar = V.inView(secao, (entry) => secao.classList.add('ativa'), { amount: 0.5 });
V.scrollProgress(artigo, (p) => { barra.style.transform = 'scaleX(' + p + ')' });

O alvo de V.animate pode ser um elemento, uma lista, um NodeList ou um seletor CSS. V.spring integra uma mola entre dois números e entrega o valor a cada quadro sem tocar no DOM, o que serve para rolagem suave, contadores e qualquer outro valor numérico.

v-flip e v-parallax

v-flip guarda a posição do elemento e, quando ela muda entre atualizações, anima do lugar antigo para o novo — a técnica FLIP. É o que faz uma lista reordenada deslizar em vez de saltar. Combine com :key, para que os elementos sejam reaproveitados em vez de recriados. 

<li v-for="item in itensOrdenados" :key="item.id" v-flip>{ item.nome }</li>
<li v-flip="{ duration: 300, easing: 'easeInOut' }">...</li>

<img v-parallax="0.3" src="/fundo.jpg" alt="">
<img v-parallax="-0.2" src="/frente.png" alt="">

v-parallax desloca o elemento conforme a rolagem; valores negativos invertem o sentido. Com prefers-reduced-motion, ele não faz nada.

Movimento reduzido

Respeitado por padrão

Tudo aqui respeita prefers-reduced-motion: reduce: nesse caso o estado final é aplicado na hora, sem quadros intermediários. O resultado é o mesmo, sem o movimento. Só use force quando a animação carrega significado que o estado final sozinho não transmite.
