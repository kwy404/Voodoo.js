Fundamentos

Campos de formulário com v-model

Um campo precisa refletir o estado, e o estado precisa refletir o campo. O v-model faz os dois sentidos de uma vez, em qualquer tipo de campo, e converte o valor de acordo com o que aquele campo é.

Todos os tipos de campo

<div v-data="{ nome: '', bio: '', aceito: false, uf: 'SP', tags: [], pagamento: 'pix' }">
  <div class="linha"><input v-model="nome" placeholder="Nome"></div>
  <div class="linha"><textarea v-model="bio" placeholder="Bio"></textarea></div>

  <div class="linha">
    <label><input type="checkbox" v-model="aceito"> Aceito os termos</label>
  </div>

  <div class="linha">
    <select v-model="uf"><option>SP</option><option>RJ</option><option>MG</option></select>
  </div>

  <div class="linha">
    <label><input type="checkbox" value="js" v-model="tags"> js</label>
    <label><input type="checkbox" value="css" v-model="tags"> css</label>
  </div>

  <div class="linha">
    <label><input type="radio" value="pix" v-model="pagamento"> Pix</label>
    <label><input type="radio" value="cartao" v-model="pagamento"> Cartão</label>
  </div>

  <p>{ JSON.stringify({ nome, aceito, uf, tags, pagamento }) }</p>
</div>

Modificadores

<input v-model.number="idade">
<input v-model.trim="email">
<textarea v-model.lazy="bio"></textarea>
<input v-model.debounce="busca" v-debounce="600">
<input type="file" v-model.single="foto">
ModificadorEfeito
.numberConverte para número. Texto que não vira número fica como está
.trimRemove os espaços das pontas
.lazyEscreve no change, e não a cada tecla
.debounceEspera o usuário parar de digitar; o tempo vem de v-debounce
.singleEm um campo de arquivo, guarda o primeiro arquivo em vez da lista
 
<div v-data="{ idade: 0, email: '', busca: '' }">
  <div class="linha"><input type="number" v-model.number="idade">
    <span>Daqui a dez anos: { idade + 10 }</span></div>
  <div class="linha"><input v-model.trim="email" placeholder="  com espaços  ">
    <span>[{ email }]</span></div>
  <div class="linha"><input v-model.debounce="busca" v-debounce="600" placeholder="Buscar">
    <span>{ busca }</span></div>
</div>

Sem o .number, um <input type="number"> ainda escreve número: a conversão pelo tipo do campo acontece sozinha. O modificador serve para forçar a conversão em campos de texto comuns.

Ligando a um caminho, e não a uma variável

v-model funciona em qualquer expressão atribuível, e não só em uma variável solta. Isso evita espalhar o formulário em dez chaves soltas quando ele é, na verdade, um objeto. 

<div v-data="{ form: { nome: '', endereco: { cidade: '', uf: '' } } }">
  <div class="linha"><input v-model="form.nome" placeholder="Nome"></div>
  <div class="linha">
    <input v-model="form.endereco.cidade" placeholder="Cidade">
    <input v-model="form.endereco.uf" placeholder="UF">
  </div>
  <p>{ JSON.stringify(form) }</p>
</div>

Dentro de um v-for, o mesmo vale para o item da iteração: <input v-model="tarefa.texto"> escreve no objeto certo da lista.

Reagindo à digitação

O v-watch observa o v-model do mesmo elemento e entrega $value e $old. É o caminho curto para disparar uma busca ou um cálculo quando o campo muda, sem escrever um evento à parte. 

<div v-data="{ busca: '', historico: [] }">
  <input v-model.debounce="busca" v-debounce="500"
         v-watch="$value && historico.unshift($value)" placeholder="Digite e pare">
  <ul><li v-for="(t, i) in historico.slice(0, 5)">{ t }</li></ul>
</div>
