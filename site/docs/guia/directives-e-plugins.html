Estendendo e depurando

Directives próprias e plugins

Tudo que a Voodoo.js faz por dentro está disponível para você: registrar directives, criar variáveis mágicas, acrescentar componentes, estender o objeto V e empacotar tudo isso em um plugin.

A forma curta

Uma função só, que vale para mounted e updated ao mesmo tempo. É o suficiente para a maioria dos casos. 

<div>
  <script>
    V.directive('tamanho', (el, binding) => {
      el.style.fontSize = binding.value + 'px';
    });
  </script>

  <div v-data="{ n: 18 }">
    <input type="range" min="12" max="48" v-model.number="n">
    <p v-tamanho="n">Este texto obedece a uma directive que você escreveu.</p>
  </div>
</div>

A forma com ciclo de vida

V.directive('destaque', {
  created(el, binding) {},
  beforeMount(el, binding) {},
  mounted(el, binding) { el.style.background = binding.value; },
  updated(el, binding) { el.style.background = binding.value; },
  beforeUnmount(el, binding) {},
  unmounted(el, binding) {},
  priority: 0,
  raw: false
});
Campo de bindingO que é
elO elemento
valueO valor já avaliado
oldValueO valor anterior, em updated
argO argumento depois dos dois pontos
modifiersOs modificadores depois dos pontos
expressionO texto original
scopeO escopo ativo
instanceA instância de componente mais próxima, ou null

priority define a ordem: maior roda primeiro. raw: true entrega a expressão como texto, sem avaliar, o que serve para directives que recebem seletores ou nomes.

Integrando uma biblioteca de fora

É aqui que a directive própria mais paga: envolver um componente externo uma vez e usá-lo como atributo em qualquer lugar. 

V.directive('datepicker', {
  mounted(el, binding) {
    const picker = new AlgumaBibliotecaDeData(el, {
      formato: binding.arg || 'dd/mm/yyyy',
      inicial: binding.value,
      onChange: (valor) => {
        el.value = valor;
        el.dispatchEvent(new Event('input', { bubbles: true }));
      }
    });
    el.__picker = picker;
  },
  updated(el, binding) { el.__picker.setValue(binding.value); },
  unmounted(el) { el.__picker.destroy(); }
});
<input v-datepicker:dd-mm-yyyy="form.nascimento" v-model="form.nascimento">
O detalhe que faz funcionar

O dispatchEvent de um input é como uma integração externa avisa o v-model. Sem ele, a biblioteca escreve no campo e o estado não fica sabendo.

Controle fino, com defineDirective

Para casos que precisam de efeitos próprios, limpeza explícita ou controle da subárvore: 

import { defineDirective, PRIORITY } from 'voodoojs';

defineDirective(
  'contador-regressivo',
  ({ el, evaluate, effect, cleanup }) => {
    let timer = null;

    effect(() => {
      const alvo = new Date(evaluate());
      clearInterval(timer);
      timer = setInterval(() => {
        const restante = Math.max(0, alvo - Date.now());
        el.textContent = Math.floor(restante / 1000) + 's';
        if (restante === 0) clearInterval(timer);
      }, 1000);
    });

    cleanup(() => clearInterval(timer));
  },
  { priority: PRIORITY.DEFAULT }
);
ContextoO que é
elO elemento que declarou o atributo
scopeO escopo ativo
expressionO texto do atributo
arg, modifiersArgumento e modificadores
rawO nome completo do atributo, útil em mensagens de erro
evaluate(expr?)Avalia a expressão. Nunca lança
effect(fn)Cria um efeito reativo já ligado à limpeza do elemento
cleanup(fn)Roda quando o elemento sai do DOM
walk(no, escopo)Inicializa HTML criado pela directive

As opções de registro são priority e terminal, que impede o walker de descer nos filhos — é o que v-for e v-if usam. As prioridades estão em V.PRIORITY: IGNORE (100), FOR (90), IF (80), DATA (70), COMPONENT (65), REF (60), MODEL (40), BIND (30), DEFAULT (0), INIT (-10) e TRANSITION (-20).

Nomes já ocupados

O nome registrado não inclui o prefixo: V.directive('toggle', ...) responde a v-toggle — e sobrescreve a directive interna de mesmo nome. Antes de escolher um nome, confira V.directives, que é o Map com tudo que já está registrado. Um prefixo próprio, como v-acme-toggle, evita a colisão de vez.

Variáveis mágicas próprias

<div>
  <script>
    V.magic('$usuario', () => ({ nome: 'Ana', plano: 'Pro' }));
    V.magic('$altura', (scope) => scope.el.offsetHeight);
  </script>

  <p>Olá, { $usuario.nome } — plano { $usuario.plano }.</p>
  <p>A altura deste escopo é { $altura } pixels.</p>
</div>

O getter recebe o escopo ativo, então a magia pode depender de onde foi usada. O cifrão é acrescentado automaticamente quando você não escreve. Magias são somente leitura, com exceção das que expõem um método set próprio.

Empacotando em um plugin

const meuPlugin = {
  name: 'analytics',
  install(V, opcoes) {
    V.rastrear = (evento, dados) => enviar(opcoes.chave, evento, dados);

    V.directive('track', (el, binding) => {
      el.addEventListener('click', () => V.rastrear(binding.value));
    });

    V.magic('$rastrear', () => V.rastrear);
  }
};

V.use(meuPlugin, { chave: 'abc123' });

A forma curta em função também funciona:

V.use((V, opcoes) => {
  V.config.globals.APP = opcoes;
}, { versao: '2.0' });

O mesmo plugin instalado duas vezes é ignorado na segunda. Dentro do install cabe qualquer coisa: componentes, regras de validação com V.validator, máscaras com V.registerMask, ou métodos novos no próprio V. 

const brasilPlus = {
  install(V) {
    V.validator('titulo-eleitor', (valor) => V.unmask(valor).length === 12, 'Título inválido.');
    V.registerMask('titulo', '9999 9999 9999');
  }
};

V.use(brasilPlus);
Para usar no HTML, libere como global

O que você acrescenta em V não fica visível dentro das expressões, que enxergam só os escopos, as magias e uma lista fechada de globais. Publique o que precisar em V.config.globals, ou crie uma magia com V.magic.
