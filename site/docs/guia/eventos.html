Fundamentos

Eventos e modificadores

O usuário clica, digita, envia. Alguma coisa precisa acontecer. Toda a escuta de eventos cabe em um atributo, e os modificadores dão de graça o que normalmente vira código de apoio: preventDefault, stopPropagation, clique fora, espera de digitação.

Três escritas, o mesmo resultado

<div v-data="{ n: 0 }">
  <button @click="n++">Somar</button>
  <button v-on:click="n = 0">Zerar</button>
  <button v-click="n--">Subtrair</button>
  <p>{ n }</p>
</div>

@evento é a mais curta, v-on:evento é a completa, e v-click, v-input, v-keyup e outros atalhos existem para quem prefere um nome único por linha. Escolha uma e mantenha no projeto inteiro.

Modificadores

Depois do nome do evento, um ponto liga comportamentos comuns: 

<form @submit.prevent="salvar()">Não recarrega a página</form>
<div class="overlay" @click.self="fechar()">Só o clique no próprio overlay conta</div>
<button @click.once="comecar()">Roda uma vez e desliga</button>
<div @keydown.escape.window="fechar()">Escuta no window inteiro</div>
<div @click.outside="fecharMenu()">Clique em qualquer lugar fora daqui</div>
ModificadorO que faz
.preventpreventDefault() antes de rodar a expressão
.stopstopPropagation(), o evento não sobe
.selfSó dispara quando o alvo é o próprio elemento
.onceRoda uma vez e remove o ouvinte
.captureEscuta na fase de captura
.passiveMarca o ouvinte como passivo, útil em rolagem e toque
.windowInstala o ouvinte no window
.documentInstala o ouvinte no document
.outsideDispara em cliques fora do elemento
.debounceEspera o usuário parar antes de rodar
.throttleLimita a uma execução por intervalo
 
<div v-data="{ texto: '', vezes: 0 }">
  <input v-model="texto" @input.debounce="vezes++" v-debounce="500">
  <p>Digitou: { texto }</p>
  <p>Disparou { vezes } vezes, contando meio segundo de silêncio.</p>
</div>

Teclas

<div v-data="{ ultimo: 'nada ainda' }">
  <input placeholder="Enter, Esc ou Ctrl+Enter"
         @keyup.enter="ultimo = 'Enter'"
         @keydown.esc="ultimo = 'Esc'"
         @keydown.ctrl.enter="ultimo = 'Ctrl+Enter'">
  <p>Última tecla reconhecida: { ultimo }</p>
</div>

Nomes aceitos: .enter, .esc ou .escape, .space, .tab, .delete, .backspace, .up, .down, .left, .right, qualquer letra de .a a .z e qualquer dígito de .0 a .9. As teclas de sistema são .ctrl, .shift, .alt e .meta, e combinam com as demais na mesma escrita. 

<div @keydown.meta.k.window.prevent="abrirBusca()"></div>

Eventos que o navegador não tem

Alguns comportamentos aparecem o tempo todo em interface e não existem como evento nativo. A Voodoo os oferece com o mesmo formato dos outros: 

<button @hold.2s="apagarTudo()">Segure dois segundos para apagar</button>
<div @visible="carregarMais()">Dispara quando entra na área visível</div>
<div @swipeleft="proximo()" @swiperight="anterior()">Gestos de arrastar</div>
<button v-hotkey="ctrl+k" @click="abrirPaleta()">Atalho global de teclado</button>

E alguns apelidos mais legíveis para eventos que já existem: @hover para mouseenter, @unhover para mouseleave, @tap para click, @press para pointerdown, @release para pointerup, @rightclick para contextmenu e @type para input. 

<div v-data="{ estado: 'parado' }">
  <button @hold.1s="estado = 'segurou um segundo!'"
          @hover="estado = 'passou o mouse'"
          @unhover="estado = 'saiu'">
    Passe o mouse, ou segure o clique
  </button>
  <p>{ estado }</p>
</div>

Dentro do handler

Três variáveis estão sempre disponíveis na expressão de um evento: 

<input @input="busca = $event.target.value">
<button @click="$el.classList.add('clicado')">Uso o próprio elemento</button>
<section @filtro="aplicar($detail)">Recebo o detalhe de um evento customizado</section>

$event é o evento, $el é o elemento e $detail é o detail de um CustomEvent.

Emitindo os seus próprios eventos

$dispatch emite um CustomEvent que sobe pela árvore, o que permite a um trecho avisar outro sem que os dois compartilhem estado. 

<div v-data="{ recebido: '' }" @produto-escolhido="recebido = $detail.nome">
  <button @click="$dispatch('produto-escolhido', { nome: 'Caneca' })">Escolher caneca</button>
  <button @click="$dispatch('produto-escolhido', { nome: 'Camiseta' })">Escolher camiseta</button>
  <p>Escolhido: { recebido || 'nada' }</p>
</div>

Limpeza automática

Você não precisa remover nada

Todo ouvinte instalado por uma directive é removido sozinho quando o elemento sai do DOM, inclusive os que foram registrados em window ou document pelos modificadores .window e .document. Um v-if que fecha leva junto tudo o que estava escutando lá dentro.
