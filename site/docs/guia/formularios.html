Dados e formulários

Formulários que validam e enviam sozinhos

Um cadastro comum precisa de validação, mensagem de erro por campo, máscara, envio por AJAX, aviso de sucesso e tratamento do erro que o servidor devolve. Costuma ser o trecho mais chato de qualquer página, e é o que a Voodoo resolve com mais atributos por linha.

O formulário inteiro

<form v-submit="/api/usuarios"
      v-method="POST"
      v-validate
      v-toast-success="Usuário cadastrado!"
      v-toast-error="Não foi possível cadastrar."
      v-reset-success
      v-redirect="/usuarios">

  <input name="nome" v-required v-minlength="3">
  <input name="email" type="email" v-required v-email>
  <input name="cpf" v-mask="cpf" v-cpf>
  <input name="telefone" v-mask="phone" v-phone>
  <input name="senha" type="password" v-strong-password>
  <input name="senha2" type="password" v-match="senha">

  <button type="submit" :disabled="$form.loading">
    { $form.loading ? 'Enviando...' : 'Salvar' }
  </button>
</form>

Sem uma linha de JavaScript: valida, mostra o erro embaixo de cada campo, envia por AJAX, mostra o aviso, limpa o formulário e redireciona.

A validação, funcionando

A validação não depende de servidor, então este bloco roda de verdade. Escreva um e-mail inválido, um CPF qualquer, e saia do campo com Tab: 

<form v-validate>
  <div class="linha"><input name="nome" placeholder="Nome" v-required v-minlength="3"></div>
  <div class="linha"><input name="email" placeholder="E-mail" v-required v-email></div>
  <div class="linha"><input name="cpf" placeholder="CPF" v-mask="cpf" v-cpf></div>
  <div class="linha"><input name="idade" placeholder="Idade" v-validate-between="18,120"></div>
</form>

O campo reprovado ganha a classe v-invalid e aria-invalid="true", e a mensagem entra logo depois dele com role="alert" e aria-describedby ligando os dois. O v-validate desliga a validação nativa do navegador e assume o controle, para que a aparência e o texto sejam os seus, iguais em todos os navegadores.

Quando cada checagem acontece

Sozinho, o v-validate confere campo por campo: quando o campo perde o foco, quando muda, e a cada tecla depois que ele já errou uma vez. A conferência do formulário inteiro, antes de enviar, é feita pelo v-submit — é ele que segura o envio, marca todos os campos reprovados de uma vez e leva o foco para o primeiro deles. Um formulário que trata o envio por conta própria, com @submit.prevent, precisa chamar V.validateForm($el) se quiser essa conferência final.

O estado do formulário

Todo formulário com v-submit publica a variável $form para o que estiver dentro dele: 

<form v-submit="/api/contato">
  <input name="email" v-required v-email>

  <p v-show="$form.errors.email">{ $form.errors.email }</p>
  <p v-show="$form.success">{ $form.message || 'Recebemos sua mensagem.' }</p>

  <button :disabled="$form.loading">Enviar</button>
</form>
Campo de $formO que guarda
loadingVerdadeiro enquanto a requisição está em andamento
savingVerdadeiro durante um salvamento automático
successVerdadeiro depois de um envio bem-sucedido
errorsMapa de campo para mensagem
messageMensagem geral devolvida pelo servidor
dataCorpo da resposta
statusCódigo HTTP da resposta
dirtyVerdadeiro quando algum campo foi alterado
progressProgresso do upload, de 0 a 100

Erros vindos do servidor

Uma resposta 422, ou qualquer resposta com um mapa de erros, é distribuída de volta para os campos certos. Os três formatos abaixo são entendidos sem configuração: 

{ "errors": { "email": "Já cadastrado" } }
{ "email": ["Já cadastrado"] }
{ "message": "Dados inválidos", "errors": { "cpf": "Inválido" } }

Mensagens sem campo correspondente viram um resumo no topo. O foco vai para o primeiro campo com problema, o que evita o clássico formulário que falha em um campo fora da tela.

As regras disponíveis

Como atributo curto: v-required, v-email, v-url, v-number, v-integer, v-minlength, v-maxlength, v-min, v-max, v-match, v-regex, v-cpf, v-cnpj, v-cep, v-phone, v-date, v-accepted e v-strong-password.

Na forma longa v-validate-<nome>, todas as anteriores mais decimal, alpha, alphanumeric, between, same, different, in, notin, after, before, creditcard e unique, que é assíncrona e consulta uma URL. 

<input v-validate-between="10,100">
<input v-date v-validate-before="hoje">
<input name="email" v-validate-unique="/api/checar-email">

CPF e CNPJ conferem os dígitos verificadores de verdade, e cartão passa por Luhn — não é só contagem de caracteres. A lista completa, com o texto padrão de cada mensagem, está na referência de validação.

Mensagem própria e regra própria

<input v-cpf v-error-message="Este CPF não confere.">
<input v-required v-error-target="#erro-do-nome">
V.validator('par', (valor) => Number(valor) % 2 === 0, 'Informe um número par.');
<input v-validate-par>

Registrar uma regra cria automaticamente a directive v-validate-par. É o mesmo caminho para regras de negócio: um CNPJ que precisa estar em uma lista, um cupom que só vale em certas datas. 

<div>
  <script>
    V.validator('par', (v) => Number(v) % 2 === 0, 'Informe um número par.');
  </script>
  <form v-validate>
    <div class="linha"><input name="n" placeholder="Um número par" v-validate-par></div>
  </form>
</div>

Arquivos, rascunho automático e proteção contra sair

<input type="file" name="anexo" v-upload="/api/upload" v-progress="#barra">

<div v-dropzone="/api/upload" v-field="anexos" accept="image/*" multiple>
  Arraste imagens aqui
</div>

<form v-autosave="/api/rascunhos/7" v-method="PUT" v-guard="Você tem alterações não salvas.">
  <textarea name="corpo"></textarea>
</form>
  • v-upload envia o arquivo assim que ele é escolhido, com progresso em v-progress.
  • v-dropzone aceita arquivos arrastados e guarda o resultado no campo indicado por v-field.
  • v-autosave salva o rascunho enquanto a pessoa escreve.
  • v-guard avisa antes de sair da página com alterações pendentes.

Formulário sem servidor

Nem todo formulário envia para uma API. Quando o destino é a própria página, use @submit.prevent e trate no estado — a validação continua funcionando do mesmo jeito: 

<div v-data="{ itens: [], texto: '' }">
  <form v-validate @submit.prevent="itens.push(texto); texto = ''">
    <div class="linha">
      <input name="texto" v-model="texto" v-required v-minlength="3" placeholder="Nova tarefa">
      <button type="submit">Adicionar</button>
    </div>
  </form>
  <ul><li v-for="(t, i) in itens">{ t }</li></ul>
</div>
