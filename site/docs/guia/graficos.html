Interface and effects

Charts

Charts in plain SVG, with no external dependency at all. The whole drawing is generated as text and handed to the container in one go, which keeps redrawing cheap even with data changing on every frame.

voodoo.full.min.js only

The chart module exists only in the full build.

v-chart

<div v-data="{
  sales: [12, 19, 8, 25, 30, 22],
  months: ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun']
}">
  <div v-chart="{ type: 'line', data: sales, labels: months, smooth: true }"></div>
  <button @click="sales.push(Math.round(Math.random() * 40)); months.push('Jul')">
    Add a month
  </button>
</div>

The chart is reactive: changing one number inside the array redraws it, because the effect walks the whole structure and subscribes to each value.

With reactive data, use the object form

The v-chart-* attributes are read on mount and serve static charts well, but the type declared in them does not survive the first data update. With v-chart="{ type: 'bar', data: sales }" everything stays right on every redraw.

The eleven types

TypeWhat it is for
lineChange over time. The default
areaThe same as the line, with the area filled in
barVertical bars
columnHorizontal bars
stackedStacked bars, for composition
pieA pie, for share
donutA doughnut, with room in the middle
sparklineA tiny trend, with no axes, to fit in a cell
radarComparison across several dimensions
scatterA scatter plot, with x and y
progressCircular progress
 
<div v-data="{ kind: 'bar', values: [12, 19, 8, 25, 30] }">
  <select v-model="kind">
    <option>line</option><option>area</option><option>bar</option>
    <option>column</option><option>pie</option><option>donut</option>
    <option>radar</option><option>sparkline</option>
  </select>
  <div v-chart="{ type: kind, data: values, labels: ['A', 'B', 'C', 'D', 'E'] }"></div>
</div>

Data shapes

Loose numbers, with the labels separate:

{ type: 'bar', data: [12, 19, 8], labels: ['Jan', 'Feb', 'Mar'] }

Named points:

{ type: 'pie', data: [
  { label: 'Organic', value: 48 },
  { label: 'Paid', value: 32 },
  { label: 'Direct', value: 20 }
] }

Named series, for several lines or bars:

{ type: 'line', labels: ['Jan', 'Feb', 'Mar'], data: [
  { name: '2025', data: [10, 14, 12] },
  { name: '2026', data: [16, 18, 25], color: '#FF3D8B' }
] }

A scatter plot, with coordinates, and a single number for progress:

{ type: 'scatter', data: [{ x: 1, y: 4 }, { x: 2, y: 7 }, { x: 3, y: 3 }] }
{ type: 'progress', data: 68 }
<div v-data="{ channels: [
  { label: 'Organic', value: 48 },
  { label: 'Paid', value: 32 },
  { label: 'Direct', value: 20 }
] }">
  <div v-chart="{ type: 'donut', data: channels, showValues: true }"></div>
</div>

For static charts, the same settings fit in attributes:

<div v-chart="[12, 19, 8, 25]" v-chart-type="bar" v-chart-height="200"></div>
<div v-chart="values" v-chart-format="currency" v-chart-colors="#6D3BF5,#2ED9A5"></div>
<div v-chart="values" v-chart-grid="false" v-chart-legend="false"></div>

Colours

With no colors, the chart uses the brand palette:

#6D3BF5  #FF3D8B  #2ED9A5  #FFB35C  #9B7BFF  #FF4D4D  #14111F  #3BB6F5

It lives in V.chartColors and in V.charts.colors. The grid, text and background colours come from the --v-* variables, so the chart follows the theme and the configured palette, including when the visitor switches theme with the page open.

From JavaScript

const chart = V.renderChart(document.querySelector('#sales'), {
  type: 'area',
  data: [12, 19, 8, 25, 30],
  labels: ['Jan', 'Feb', 'Mar', 'Apr', 'May'],
  smooth: true
});

chart.update({ data: newData });
chart.destroy();

V.chart is an alias of V.renderChart.

Accessibility

Each chart receives role="img" and an aria-label written from the data, with the type, the number of series, the minimum, the maximum and the average. Each shape has a <title> of its own, read out on focus. The entry animation respects prefers-reduced-motion.

Offer the numbers as well

A well-written label helps, but it does not replace the data. For sets that matter, put a table next to it, inside a <details>, if it takes up too much room. 

<div v-chart="{ type: 'bar', data: sales, labels: months }"></div>

<details>
  <summary>See the data as a table</summary>
  <VTable columns="month:Month, value:Value:right" :rows="salesTable"></VTable>
</details>
