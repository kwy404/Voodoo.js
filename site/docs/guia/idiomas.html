Interface e efeitos

Idiomas

Internacionalização reativa. Trocar o idioma não recarrega a página: todo texto que passou por t() e todo formatador de número, moeda ou data se atualiza sozinho, porque tudo lê o mesmo estado reativo.

Só no voodoo.full.min.js

O módulo de idiomas existe apenas no build completo.

Configurando

V.i18n({
  locale: 'pt-BR',
  fallback: 'en',
  messages: {
    'pt-BR': {
      comum: { salvar: 'Salvar', cancelar: 'Cancelar' },
      ola: 'Olá, {nome}!',
      itens: 'nenhum item | {n} item | {n} itens'
    },
    en: {
      comum: { salvar: 'Save', cancelar: 'Cancel' },
      ola: 'Hello, {nome}!',
      itens: 'no items | {n} item | {n} items'
    }
  }
});
OpçãoPadrãoO que faz
localeV.config.localeIdioma inicial
fallbackenIdioma usado quando a chave não existe
messagesMensagens por idioma
currencyV.config.currencyMoeda padrão de c()
persisttrueGuarda o idioma escolhido no localStorage
detecttrueDetecta o idioma do navegador quando nada foi salvo
loadPathModelo de URL para carregamento sob demanda, com {locale}

A ordem de escolha é: o idioma salvo, o detectado no navegador, o declarado na opção, e por fim o fallback. O escolhido também vai para document.documentElement.lang, o que mantém leitores de tela e a hifenização do navegador coerentes.

Funcionando

<div>
  <script>
    V.i18n({
      locale: 'pt-BR',
      persist: false,
      detect: false,
      messages: {
        'pt-BR': {
          titulo: 'Carrinho',
          ola: 'Olá, {nome}!',
          itens: 'nenhum item | {n} item | {n} itens',
          comum: { salvar: 'Salvar' }
        },
        en: {
          titulo: 'Cart',
          ola: 'Hello, {nome}!',
          itens: 'no items | {n} item | {n} items',
          comum: { salvar: 'Save' }
        }
      }
    });
  </script>

  <div v-data="{ quantos: 0 }">
    <div class="linha">
      <button v-locale="pt-BR">Português</button>
      <button v-locale="en">English</button>
      <button @click="quantos++">+1</button>
    </div>

    <h4 v-t="titulo"></h4>
    <p v-text="$t('ola', { nome: 'Ana' })"></p>
    <p>{ $t('itens', quantos) }</p>
    <p>{ $c(1234.5) } · { $d('2026-08-29') }</p>
    <p v-text="$n(0.75, { style: 'percent' })"></p>
    <button v-t="comum.salvar"></button>
  </div>
</div>

Troque o idioma e repare que os números e a data mudam junto com o texto: eles saem dos mesmos Intl configurados pelo idioma ativo.

Mensagens

A árvore aceita aninhamento em qualquer nível, e a chave é lida por ponto:

{ comum: { botoes: { salvar: 'Salvar' } } }   // t('comum.botoes.salvar')
{ 'comum.botoes.salvar': 'Salvar' }           // o mapa achatado também funciona

Quando a chave não existe em lugar nenhum, t() devolve a própria chave. Isso é melhor do que texto vazio na tela, e facilita achar o que falta.

v-t

<button v-t="comum.salvar"></button>
<abbr v-t:title="comum.dica">?</abbr>
<span v-t="'menu.' + secao"></span>

Sem argumento, traduz o conteúdo do elemento. Com argumento, escreve no atributo indicado — o que resolve title, placeholder e aria-label.

Interpolação

<span>{ $t('ola', { nome: usuario.nome }) }</span>
<span v-t="ola" v-t-params="{ nome: usuario.nome }"></span>
Detalhe conhecido

v-t-params é lido apenas na primeira renderização. Se o texto precisa acompanhar a troca de idioma ou a mudança dos valores, use a interpolação com $t, que é totalmente reativa.

Pluralização

As formas são separadas por barra vertical:

{
  itens: 'nenhum item | {n} item | {n} itens',
  mensagens: '{n} mensagem | {n} mensagens'
}
<span>{ $t('itens', { n: carrinho.length }) }</span>
<span>{ $t('itens', carrinho.length) }</span>     <!-- atalho do mesmo caso -->
  • Duas formas seguem direto a categoria de Intl.PluralRules do idioma.
  • Três formas reservam a primeira para o zero, que é o costume em português e em inglês.
  • Quatro ou mais usam a ordem oficial das categorias do CLDR, o que cobre idiomas com dual e paucal.

A contagem é lida de n ou de count.

Trocando o idioma

<button v-locale="pt-BR">Português</button>
<button v-locale="en">English</button>
<button v-locale="idiomaEscolhido">Trocar</button>

O botão ativo recebe a classe v-locale-active. Por JavaScript, o mesmo é V.locale('en'), e $locale devolve o idioma em uso dentro de qualquer expressão.

Formatadores

MagiaFormataExemplo
$nNúmero{ $n(1234.5) } → 1.234,5
$cMoeda{ $c(1234.5) } → R$ 1.234,50
$dData{ $d(pedido.criadoEm) } → 29/08/2026
$rtTempo relativo{ $rt(pedido.criadoEm) } → há 5 minutos

Todos aceitam opções: $n(0.75, { style: 'percent' }), $c(99, 'USD'), $d(data, 'long'). Como leem o idioma ativo, eles se atualizam sozinhos na troca.
