Começando

Instalação e primeiro arquivo

A Voodoo.js é um arquivo pronto. Você baixa, coloca junto do seu HTML, aponta uma tag, e acabou. Não existe instalador, não existe passo de build, não existe arquivo de configuração obrigatório.

1. Escolha e baixe o arquivo

São três arquivos publicados. Todos são o mesmo projeto, cortado em pontos diferentes. Escolha um só.

ArquivoO que vem dentroGzipDownload
voodoo.core.min.js Reatividade, expressões, componentes, DOM encadeável, directives de estado, renderização, eventos e requisições por atributo 42 KB baixar
voodoo.min.js O anterior, mais formulários com validação, máscaras, interface completa, arrastar e soltar, diálogos, avisos e som 79 KB baixar
voodoo.full.min.js Tudo, mais gráficos, animações com física, roteador, idiomas, inspetor de reatividade e 29 componentes prontos 124 KB baixar

Na dúvida, comece pelo voodoo.min.js. Ele cobre a maioria das páginas. Troque pelo completo no dia em que precisar de gráfico, animação com mola, roteador, idiomas ou dos componentes prontos. Trocar é reescrever o src da tag: o HTML que você já escreveu continua igual.

Pelo terminal:

curl -L -o voodoo.min.js https://github.com/kwy404/Voodoo.js/raw/main/packages/voodoojs/dist/voodoo.min.js

Ou baixe o repositório inteiro pelo botão Code, ou pela release v0.5.0, e pegue os arquivos de packages/voodoojs/dist/. Cada arquivo tem um .map ao lado; copie os dois se quiser depurar o código original no inspetor.

2. Aponte uma tag para o arquivo

<script src="voodoo.min.js" defer></script>

Acabou. Não existe V.init() para chamar: a biblioteca começa sozinha assim que a página fica pronta, publica o objeto global V (e Voodoo, o mesmo objeto), aplica o tema salvo, aplica a paleta salva e percorre o document.body ligando os atributos v-*.

O defer faz o navegador terminar de ler o HTML antes de executar o arquivo. Sem ele, a biblioteca inicia mais cedo e o MutationObserver acaba fazendo o trabalho de novo — funciona, mas custa mais.

3. Escreva HTML

<div v-data="{ n: 0 }">
  <button @click="n++">Clicou { n } vezes</button>
</div>

Abra o arquivo no navegador. Clique. O número muda. Esse é o ciclo inteiro.

Seu primeiro arquivo, linha por linha

Crie um index.html ao lado do voodoo.min.js que você baixou: 

<!doctype html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <title>Meu primeiro Voodoo</title>
  <script src="voodoo.min.js" defer></script>
</head>
<body>

<div v-data="{ nome: '', count: 0 }">

  <input v-model="nome" placeholder="Seu nome">
  <h1>Olá, { nome || 'estranho' }!</h1>

  <button @click="count--">-</button>
  <strong>{ count }</strong>
  <button @click="count++">+</button>

  <p v-show="count > 5">Você clicou bastante.</p>

</div>

</body>
</html>

É este o resultado, rodando aqui:

<div v-data="{ nome: '', count: 0 }">
  <input v-model="nome" placeholder="Seu nome">
  <h3>Olá, { nome || 'estranho' }!</h3>
  <div class="linha">
    <button @click="count--">-</button>
    <strong>{ count }</strong>
    <button @click="count++">+</button>
  </div>
  <p v-show="count > 5">Você clicou bastante.</p>
</div>
  1. <script src="voodoo.min.js" defer> carrega a biblioteca.
  2. v-data="{ nome: '', count: 0 }" cria um escopo: duas variáveis que valem para aquele <div> e para tudo que estiver dentro dele.
  3. v-model="nome" liga o campo à variável nos dois sentidos. Digitou, mudou a variável; mudou a variável, mudou o campo.
  4. { nome || 'estranho' } é interpolação: escreve o valor no texto e se atualiza sozinha.
  5. @click="count++" executa a expressão no clique e avisa quem depende de count.
  6. v-show="count > 5" mostra o parágrafo apenas quando a condição é verdadeira.

O que observar: você não escreveu uma linha de JavaScript solto. Não existe querySelector, não existe addEventListener, não existe uma função de renderizar. Abra o inspetor depois de carregar: os atributos v-model, @click e v-show sumiram. Sobrou HTML limpo.

Evitando o piscar do conteúdo

Entre o navegador desenhar o HTML e a biblioteca iniciar existe um instante em que o texto bruto aparece na tela — inclusive as chaves da interpolação. O v-cloak resolve: a biblioteca remove o atributo quando termina de montar aquele trecho. 

<style>
  [v-cloak] { display: none !important; }
</style>

<div v-cloak v-data="{ carregando: true }">
  <p>{ carregando ? 'Carregando...' : 'Pronto' }</p>
</div>

A regra de [v-cloak] já vem no CSS que a biblioteca injeta, mas declarar no seu próprio arquivo garante que ela exista antes do primeiro quadro — que é justamente o momento que interessa.

Configuração pela própria tag

O jeito mais rápido de configurar é por atributos na tag do script, sem escrever JavaScript nenhum: 

<script
  src="voodoo.min.js"
  data-base-url="https://api.exemplo.com"
  data-locale="pt-BR"
  defer
></script>
AtributoEfeito
data-manualNão inicia sozinha. Você chama V.start() quando quiser
data-defer-initO mesmo que data-manual
data-prefixTroca o prefixo dos atributos, por exemplo data-v-
data-base-urlURL base das requisições de V.http e das directives HTTP
data-localeIdioma usado por formatadores de data, número e moeda
data-devtoolsLiga avisos detalhados no console
data-no-stylesNão injeta o CSS dos componentes de interface
data-no-observerDesliga o MutationObserver que inicializa HTML criado depois
data-keep-attributesMantém os atributos v-* no HTML depois de processados

A lista completa de opções, com o valor padrão de cada uma, está na referência de configuração.

Quando você precisa do data-manual

A inicialização automática acontece cedo, de propósito. Se a sua página registra componentes, directives próprias ou dados globais em outro arquivo, esse registro precisa acontecer antes da primeira varredura — senão a biblioteca passa por uma tag que ainda não conhece. 

<script src="voodoo.min.js" data-manual defer></script>
<script src="meus-componentes.js" defer></script>
<script defer>
  V.config.locale = 'pt-BR';
  V.config.currency = 'BRL';
  V.http.setBaseURL('https://api.exemplo.com');
  V.start();
</script>
Regra simples

Quem chama V.start() é sempre o último script da lista. Qualquer arquivo que registre componente, directive ou dado entra antes dele.

Prefixo válido para HTML estrito

Se o seu validador de HTML reclamar de v-text, troque o prefixo: 

<script src="voodoo.min.js" data-prefix="data-v-" defer></script>

<div data-v-data="{ n: 0 }">
  <button data-v-click="n++">Somar</button>
  <b data-v-text="n"></b>
</div>

A biblioteca sempre aceita data-v-nome, mesmo quando o prefixo configurado é outro. Os atalhos :atributo e @evento continuam funcionando nos dois modos.

Verificando se deu certo

<script>
  document.addEventListener('voodoo:ready', (e) => {
    console.log('Voodoo', V.version, 'iniciada em', e.detail.root);
  });
</script>

Se o console imprimir a versão, a biblioteca carregou e montou. Se não imprimir nada, o caminho do src está errado — a aba de rede do inspetor confirma em um segundo.
