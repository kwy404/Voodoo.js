Dados e formulários

Máscaras de campo

Máscaras de digitação que preservam a posição do cursor, inclusive quando o usuário edita o meio do texto ou apaga um separador. É o detalhe que separa uma máscara boa de uma máscara que todo mundo desliga depois de dois dias.

O básico

<div v-data="{}">
  <div class="linha"><input v-mask="cpf" placeholder="CPF"></div>
  <div class="linha"><input v-mask="phone" placeholder="Telefone"></div>
  <div class="linha"><input v-mask="cep" placeholder="CEP"></div>
  <div class="linha"><input v-mask="(99) 99999-9999" placeholder="Padrão próprio"></div>
  <div class="linha"><input v-mask-currency placeholder="Moeda"></div>
</div>

Experimente editar o meio de um número já digitado: o cursor fica onde estava. Apague em cima de um ponto: o dígito anterior é removido, e não só o separador.

Máscara e validação são coisas separadas, e combinam bem: a máscara formata enquanto se digita, a regra confere no fim. 

<input v-mask="cpf" v-cpf>
<input v-mask="cpfcnpj" placeholder="CPF ou CNPJ">
<input v-mask="phone" v-phone>

Máscara por padrão de caracteres

Quando o valor não é o nome de uma máscara conhecida, ele é lido como padrão: 

<input v-mask="(99) 99999-9999">
<input v-mask="AAA-9999">
<input v-mask="SSSS SSSS">
<input v-mask="\R\S 9999">
TokenAceita
9Dígito
ALetra, com acento
SLetra ou dígito
*Qualquer caractere
\Escapa o próximo caractere, tornando literal

Qualquer outro caractere do padrão entra como separador fixo e só aparece quando ainda existe conteúdo depois dele — por isso a máscara não empurra parênteses vazios para dentro de um campo ainda em branco.

v-model e o valor limpo

Por padrão o estado recebe o texto formatado. Com .unmask (ou .raw), ele recebe o valor limpo, enquanto a tela continua mostrando a máscara — que é quase sempre o que o servidor quer receber. 

<div v-data="{ form: { cpf: '', preco: '' } }">
  <div class="linha"><input v-mask.unmask="cpf" v-model="form.cpf" placeholder="CPF"></div>
  <div class="linha"><input v-mask-currency.unmask v-model="form.preco" placeholder="Preço"></div>
  <p>Vai para o servidor: { JSON.stringify(form) }</p>
</div>

v-mask roda antes de v-model, então o estado nunca vê o valor pela metade.

Moeda e porcentagem

v-mask-currency digita da direita para a esquerda, como uma calculadora: 

<input v-mask-currency>                      <!-- R$ 1.234,56 -->
<input v-mask-currency="US$ ">               <!-- US$ 1.234,56 -->
<input v-mask-currency v-mask-decimals="0">  <!-- R$ 1.234 -->
<input v-mask-currency v-mask-suffix=" /mês">
<input v-mask-currency.plain>                <!-- 1.234,56, sem prefixo -->
<input v-mask-currency.dot>                  <!-- 1,234.56, no padrão americano -->

Cuidados

Máscara só em campo textual

v-mask precisa de <input> ou <textarea> com tipo textual. Tipos como number, range, date e color não aceitam máscara, porque o navegador já controla o valor. Use type="text" com inputmode, que traz o teclado numérico no celular sem tirar o controle do campo: 

<input type="text" inputmode="numeric" v-mask="cpf">
<input type="text" inputmode="decimal" v-mask-currency>

Um valor que já vem do servidor no value é formatado assim que a directive monta, então uma tela de edição abre com tudo no lugar.

Criando máscaras

Por padrão de caracteres:

V.registerMask('processo', '9999999-99.9999.9.99.9999');
V.registerMask('renavam', '99999999999');

Por função, para casos que mudam conforme o conteúdo:

V.registerMask('inscricao', (valor) => {
  const digitos = valor.replace(/\D/g, '');
  return digitos.length <= 9
    ? V.applyMask(digitos, '999.999.999')
    : V.applyMask(digitos, '999.999.999.999');
});
<div>
  <script>
    V.registerMask('processo', '9999999-99.9999.9.99.9999');
  </script>
  <input v-mask="processo" placeholder="Número do processo">
</div>

Por JavaScript

V.mask('12345678901', 'cpf');        // '123.456.789-01'
V.applyMask('1234', '99-99');        // '12-34'
V.unmask('123.456.789-01');          // '12345678901'
V.unmask('R$ 1.234,56', 'currency'); // '1234.56'

V.mask.currency('123456');           // 'R$ 1.234,56'
V.mask.percent('1250');              // '12,50%'

A tabela completa de V.mask está na referência de máscaras.

Como o cursor é tratado

A implementação conta os caracteres significativos antes do cursor, reformata o texto e recoloca o cursor depois do mesmo número de caracteres significativos. Daí vêm as três consequências que interessam: editar o meio do texto não joga o cursor para o fim; apagar em cima de um separador remove o caractere útil anterior; e máscaras numéricas mantêm o cursor no fim, antes do sufixo.

A propriedade value do input é substituída, de forma que ler input.value devolva o valor limpo quando .unmask está ativo, e escrever nela sempre passe pela máscara. Ao desmontar, a propriedade original é restaurada.
