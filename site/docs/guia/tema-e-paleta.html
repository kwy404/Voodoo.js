Interface e efeitos

Tema e paleta

Dois sistemas complementares: o tema, que alterna entre claro e escuro, e a paleta, que gera todas as cores da interface a partir de poucas cores base. Os dois vivem em variáveis CSS, então o seu próprio CSS anda junto sem esforço.

Tema claro e escuro

O tema é aplicado no elemento raiz, com o atributo data-theme:

<html data-theme="dark">

Quando o usuário nunca escolheu, o atributo não existe e vale a preferência do sistema, lida por prefers-color-scheme. 

<div>
  <button v-theme-toggle>Alternar tema</button>
  <p v-show="$theme.resolved === 'dark'">Você está no tema escuro.</p>
  <p v-show="$theme.resolved === 'light'">Você está no tema claro.</p>
</div>

O botão recebe aria-pressed, um aria-label descritivo e data-v-theme com o tema em uso. 

V.theme.current;    // 'light', 'dark' ou 'system'
V.theme.resolved;   // 'light' ou 'dark', já resolvendo 'system'
V.theme.set('dark');
V.theme.set('system');
V.theme.toggle();   // devolve o tema aplicado
Sem piscar

A escolha fica no localStorage, na chave voodoo:theme, e é aplicada pelos builds de navegador antes do primeiro render. É por isso que a página não abre branca para quem escolheu o tema escuro.

Escrevendo CSS que segue o tema

.minha-caixa {
  background: var(--v-surface);
  color: var(--v-text);
  border: 1px solid var(--v-border);
  border-radius: var(--v-radius);
  box-shadow: var(--v-shadow);
}

Como as variáveis já mudam com o tema, você não precisa escrever duas versões da mesma regra.

A paleta

V.palette() gera, a partir de poucas cores base, a escala completa de tons de 50 a 900, a versão de tema escuro e a cor de texto com melhor contraste sobre cada cor, tudo escrito como variáveis CSS no :root.

O cálculo acontece em OKLCH, um espaço perceptualmente uniforme: degraus com a mesma diferença de luminância parecem igualmente distantes para o olho, o que não acontece em HSL. A cor de texto usa o cálculo real de luminância relativa da WCAG, então o resultado é sempre legível. 

V.palette({ primary: '#6D3BF5', accent: '#FF3D8B', radius: '12px', font: 'Inter' });
V.palette({ preset: 'oceano' });
OpçãoO que faz
presetPonto de partida. As cores informadas sobrescrevem
primary, accent, success, warning, danger, infoCores base
neutralCor que tinge fundos, textos e bordas. Padrão: a matiz da primária
radiusRaio das bordas, como 12px ou 0.75rem
fontFamília principal. A página continua responsável por carregar a fonte
monoFontFamília monoespaçada, usada por VCodeBlock
persistSalva a escolha no localStorage. Padrão true

Todos têm contraste verificado nos dois temas.

<div>
  <script>
    V.data({ trocarPaleta: (nome) => V.palette.use(nome) });
  </script>

  <div v-data="{ presets: ['violeta', 'oceano', 'floresta', 'poente', 'grafite'] }">
    <div class="linha">
      <button v-for="p in presets" @click="trocarPaleta(p)">{ p }</button>
    </div>
    <VButton variant="primary">Botão primário</VButton>
    <VBadge tone="success">Sucesso</VBadge>
    <VAlert tone="info" title="Aviso">A paleta inteira muda de uma vez.</VAlert>
  </div>
</div>
V.palette.use('floresta');   // troca só o preset, mantendo raio e fonte
V.palette.names;             // ['violeta', 'oceano', 'floresta', 'poente', 'grafite']
V.palette.reset();           // volta ao padrão e apaga a escolha salva
V.palette.current;           // paleta em uso, com todas as escalas

Depois de V.palette(), o conjunto cresce com fundos intermediários, sombras menor e maior, raios maiores, anel de foco, famílias tipográficas e as escalas de 50 a 900 de cada cor base. A lista completa está na referência de configuração.

Cores derivadas, e conferir contraste

V.palette.scale('#6D3BF5')['700'];           // tom escuro da escala
V.palette.scale('#6D3BF5', true);            // escala do tema escuro
V.palette.contrastText('#6D3BF5');           // '#fff' ou '#000', o que ler melhor
V.palette.contrastRatio('#6D3BF5', '#fff');  // razão WCAG, de 1 a 21
V.palette.luminance('#6D3BF5');              // luminância relativa
Use durante o desenvolvimento

contrastRatio devolve a razão real: 4.5 é o mínimo da WCAG AA para texto normal e 3 para texto grande. É mais rápido conferir uma cor no console do que descobrir o problema depois, em um teste de acessibilidade.

Desligando o CSS injetado

<script src="voodoo.full.min.js" data-no-styles defer></script>

Nenhum estilo é injetado. Os componentes continuam funcionando, mas sem aparência, e você fica responsável por escrever as regras das classes v-*. Se você usa Tailwind, o caminho mais confortável costuma ser o contrário: manter o CSS injetado e apontar as cores do Tailwind para as variáveis --v-*, de forma que os dois sistemas andem juntos.
