Componentes prontos e props

Os 29 componentes registrados pelo voodoo.full.min.js, um a um. Cada um aceita as duas escritas, <VButton> e <v-button>. O guia de componentes prontos mostra como usá-los; esta página lista o que cada um recebe.

Regras que valem para todos

  • Nenhuma cor fica fixa no CSS. Tudo vem das variáveis geradas por V.palette(), então trocar a paleta muda a interface inteira na hora, nos dois temas.
  • Props booleanas aceitam três escritas. O atributo vazio (loading), o texto (loading="true") e a ligação reativa (:loading="salvando"). Contam como verdadeiro: atributo vazio, true, 1, sim, yes.
  • Listas aceitam três formatos: o nome de uma variável do escopo em volta, uma lista literal separada por vírgulas, ou uma ligação reativa.
  • Os controles de formulário são desenhados do zero. Cada um usa appearance: none e guarda um elemento nativo escondido, o que mantém a acessibilidade e o envio dentro de um <form>. Todos funcionam com v-model no próprio hospedeiro.
  • Feche sempre a tag. <VInput ... /> não fecha nada em HTML: escreva <VInput ...></VInput>. 
<VSelect options="estados"></VSelect>          <!-- variável do v-data em volta -->
<VSelect options="SP, RJ, MG"></VSelect>       <!-- lista literal -->
<VSelect :options="listaCarregada"></VSelect>  <!-- ligação reativa -->

VSelect

Select desenhado do zero, com busca, seleção múltipla e navegação por teclado.

PropPadrão

Emite change com o valor atual — texto, ou array quando multiple. Formatos aceitos em options:

Emite sort com { key, direction }. As colunas aceitam três formatos:

['nome', 'email']                                   // rótulo derivado da chave

Chaves com ponto funcionam: cliente.nome.
