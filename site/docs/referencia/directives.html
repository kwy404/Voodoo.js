Directives por categoria

São 257 atributos registrados. Esta página traz os principais, agrupados por assunto. A lista completa e exata do que está registrado sai com V.directives no console do navegador — ela reflete o build que você carregou, e não a documentação.

Como um atributo é lido

v-on:click.prevent.once="salvar()"
│  │  │     │              └── expressão
│  │  │     └── modificadores, separados por ponto
│  │  └── argumento, depois dos dois pontos
│  └── nome da directive
└── prefixo
EscritaEquivale a
@click="..."v-on:click="..."
:href="..."v-bind:href="..."
.value="..."v-bind:value.prop="..."
data-v-nomev-nome, sempre aceito

Modificadores são sempre nomes soltos, porque um = dentro do nome do atributo não sobrevive ao parser de HTML. Quando uma directive precisa de um número, ela oferece um atributo próprio — v-debounce, v-autosave-delay, v-mask-decimals — ou aceita o valor como modificador direto, como em @hold.2s.

Ordem de execução

Em um mesmo elemento a ordem é fixa, e não depende de como você escreveu os atributos:

  1. v-ignore e v-pre cancelam tudo naquela subárvore.
  2. Directives terminais — v-for, v-if, v-else-if, v-else — assumem o controle.
  3. v-data e v-component criam o escopo usado pelo resto.
  4. As demais rodam por prioridade decrescente: v-ref, v-mask, v-model, v-bind, o resto, v-init, e por fim as classes de transição.
  5. Os filhos são percorridos com o escopo resultante.

Um detalhe de implementação que resolve um problema real

A gaveta lateral leva o painel para o corpo do documento enquanto está aberta, então ela funciona mesmo quando o v-drawer mora dentro de um contêiner com filter, transform ou backdrop-filter — propriedades que quebrariam o posicionamento fixo. O menu suspenso faz o mesmo com overflow: hidden.

Os atributos somem do HTML

<!-- você escreve -->
<button v-click="salvar()" :disabled="carregando">Salvar</button>

<!-- o inspetor mostra -->
<button disabled>Salvar</button>

Os valores continuam guardados no runtime, então o comportamento não muda. Duas consequências: nunca escreva CSS apoiado em seletores como [v-tab], e el.getAttribute('v-alguma-coisa') devolve null depois da montagem. Para desligar, use V.config.cleanAttributes = false, ou o atributo data-keep-attributes na tag <script>.
