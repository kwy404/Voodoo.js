Tipos de gráfico

Os onze tipos, o formato de dados que cada um espera e todas as opções. O guia de gráficos mostra o módulo funcionando. Tudo aqui existe apenas no voodoo.full.min.js.

Os tipos, e o dado que cada um espera

TipoPara que serveFormato esperado
lineEvolução ao longo do tempo. PadrãoNúmeros, ou séries nomeadas
areaIgual à linha, com a área preenchidaNúmeros, ou séries nomeadas
barBarras verticaisNúmeros, pontos nomeados ou séries
columnBarras horizontaisNúmeros, pontos nomeados ou séries
stackedBarras empilhadas, para composiçãoSéries nomeadas
piePizza, para participaçãoPontos nomeados
donutRosca, com espaço no meioPontos nomeados
sparklineTendência miúda, sem eixosNúmeros
radarComparação de várias dimensõesNúmeros com labels, ou séries
scatterDispersãoPontos { x, y }
progressProgresso circularUm número só

Formatos de dados

// números soltos, com rótulos separados
{ type: 'bar', data: [12, 19, 8], labels: ['Jan', 'Fev', 'Mar'] }

// pontos nomeados
{ type: 'pie', data: [
  { label: 'Orgânico', value: 48 },
  { label: 'Pago', value: 32 }
] }

// séries nomeadas
{ type: 'line', labels: ['Jan', 'Fev', 'Mar'], data: [
  { name: '2025', data: [10, 14, 12] },
  { name: '2026', data: [16, 18, 25], color: '#FF3D8B' }
] }

// dispersão
{ type: 'scatter', data: [{ x: 1, y: 4 }, { x: 2, y: 7 }] }

// progresso
{ type: 'progress', data: 68, max: 100 }

Atributos v-chart-*

v-chart-type, v-chart-height, v-chart-format, v-chart-colors, v-chart-max, v-chart-min, v-chart-smooth, v-chart-grid, v-chart-legend, v-chart-values, v-chart-tooltip e v-chart-animate. Os booleanos aceitam o atributo vazio, true, 1, false e 0.

Eles são lidos só na montagem

Com dados reativos, declare tudo no objeto — v-chart="{ type: 'bar', data: vendas }" —, senão o tipo volta ao padrão na primeira atualização.

Cores

#6D3BF5  #FF3D8B  #2ED9A5  #FFB35C  #9B7BFF  #FF4D4D  #14111F  #3BB6F5

A paleta padrão está em V.chartColors e em V.charts.colors. As cores de grade, texto e fundo vêm das variáveis --v-*, então o gráfico acompanha o tema e a paleta configurada.

Por JavaScript

const grafico = V.renderChart(el, { type: 'area', data: [12, 19, 8], smooth: true });
grafico.update({ data: novosDados });
grafico.options;
grafico.destroy();
MembroO que é
V.renderChart(el, opcoes)Desenha e devolve o controle
V.chartApelido de V.renderChart
V.charts.renderO mesmo
V.charts.formatFormata um valor no padrão do gráfico
V.charts.colors, V.chartColorsA paleta padrão

Acessibilidade

Cada gráfico recebe role="img" e um aria-label escrito a partir dos dados, com o tipo, a quantidade de séries, mínimo, máximo e média. Cada forma tem um <title> próprio, lido no foco, e a animação de entrada respeita prefers-reduced-motion. Para conjuntos importantes, ofereça também os números em uma tabela.
