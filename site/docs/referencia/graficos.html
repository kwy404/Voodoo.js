Chart types

The eleven types, the data shape each one expects and every option. The charts guide shows the module at work. Everything here exists only in voodoo.full.min.js.

The types, and the data each one expects

TypeWhat it is forExpected shape
lineChange over time. The defaultNumbers, or named series
areaThe same as the line, with the area filled inNumbers, or named series
barVertical barsNumbers, named points or series
columnHorizontal barsNumbers, named points or series
stackedStacked bars, for compositionNamed series
pieA pie, for shareNamed points
donutA doughnut, with room in the middleNamed points
sparklineA tiny trend, with no axesNumbers
radarComparison across several dimensionsNumbers with labels, or series
scatterA scatter plot{ x, y } points
progressCircular progressA single number

Data shapes

// loose numbers, with the labels separate
{ type: 'bar', data: [12, 19, 8], labels: ['Jan', 'Feb', 'Mar'] }

// named points
{ type: 'pie', data: [
  { label: 'Organic', value: 48 },
  { label: 'Paid', value: 32 }
] }

// named series
{ type: 'line', labels: ['Jan', 'Feb', 'Mar'], data: [
  { name: '2025', data: [10, 14, 12] },
  { name: '2026', data: [16, 18, 25], color: '#FF3D8B' }
] }

// a scatter plot
{ type: 'scatter', data: [{ x: 1, y: 4 }, { x: 2, y: 7 }] }

// progress
{ type: 'progress', data: 68, max: 100 }

The v-chart-* attributes

v-chart-type, v-chart-height, v-chart-format, v-chart-colors, v-chart-max, v-chart-min, v-chart-smooth, v-chart-grid, v-chart-legend, v-chart-values, v-chart-tooltip and v-chart-animate. The boolean ones accept the empty attribute, true, 1, false and 0.

They are read on mount only

With reactive data, declare everything in the object , v-chart="{ type: 'bar', data: sales }", otherwise the type falls back to the default on the first update.

Colours

#6D3BF5  #FF3D8B  #2ED9A5  #FFB35C  #9B7BFF  #FF4D4D  #14111F  #3BB6F5

The default palette lives in V.chartColors and in V.charts.colors. The grid, text and background colours come from the --v-* variables, so the chart follows the theme and the configured palette.

From JavaScript

const chart = V.renderChart(el, { type: 'area', data: [12, 19, 8], smooth: true });
chart.update({ data: newData });
chart.options;
chart.destroy();

Accessibility

Every chart gets role="img" and an aria-label written from the data, carrying the type, the number of series, the minimum, the maximum and the average. Every shape has a <title> of its own, read out on focus, and the entry animation respects prefers-reduced-motion. For sets that matter, offer the numbers in a table as well.
