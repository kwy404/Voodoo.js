Qualquer outro caractere entra como separador fixo, e só aparece quando ainda existe conteúdo depois dele.

O objeto V.mask

V.mask('12345678901', 'cpf');        // '123.456.789-01'
V.applyMask('1234', '99-99');        // '12-34'
V.unmask('123.456.789-01');          // '12345678901'
V.unmask('R$ 1.234,56', 'currency'); // '1234.56'

V.mask.currency('123456');           // 'R$ 1.234,56'
V.mask.currency('123456', { prefix: '', decimals: 0, thousands: ',' });
V.mask.percent('1250');              // '12,50%'
MembroO que é
V.mask(valor, padrao)Aplica a máscara
V.mask.applyO mesmo que V.applyMask
V.mask.unmaskRemove a formatação
V.mask.registerRegistra uma máscara nomeada
V.mask.currency, V.mask.percentFormata como moeda e porcentagem
V.mask.presetsO Map com todas as máscaras registradas

Registrando máscaras

V.registerMask('processo', '9999999-99.9999.9.99.9999');
V.registerMask('renavam', '99999999999');

V.registerMask('inscricao', (valor) => {
  const digitos = valor.replace(/\D/g, '');
  return digitos.length <= 9
    ? V.applyMask(digitos, '999.999.999')
    : V.applyMask(digitos, '999.999.999.999');
});
Só em campo textual

v-mask precisa de <input> ou <textarea> com tipo textual. number, range, date e color não aceitam máscara, porque o navegador já controla o valor. Use type="text" com inputmode.
