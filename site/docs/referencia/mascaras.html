Pattern tokens

TokenAccepts
9A digit
AA letter, accents included
SA letter or a digit
*Any character
\Escapes the next character, making it literal

Any other character goes in as a fixed separator, and only shows up while there is still content after it.

The V.mask object

V.mask('12345678901', 'cpf');        // '123.456.789-01'
V.applyMask('1234', '99-99');        // '12-34'
V.unmask('123.456.789-01');          // '12345678901'
V.unmask('R$ 1.234,56', 'currency'); // '1234.56'

V.mask.currency('123456');           // 'R$ 1.234,56'
V.mask.currency('123456', { prefix: '', decimals: 0, thousands: ',' });
V.mask.percent('1250');              // '12,50%'

Registering masks

V.registerMask('lawsuit', '9999999-99.9999.9.99.9999');
V.registerMask('renavam', '99999999999');

V.registerMask('taxId', (value) => {
  const digits = value.replace(/\D/g, '');
  return digits.length <= 9
    ? V.applyMask(digits, '999.999.999')
    : V.applyMask(digits, '999.999.999.999');
});
Text fields only

v-mask needs an <input> or a <textarea> of a textual type. number, range, date and color take no mask, because the browser already controls the value. Use type="text" with inputmode.
