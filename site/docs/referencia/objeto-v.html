O objeto V

V é ao mesmo tempo uma função e um objeto. O que estiver marcado como completo só existe no voodoo.full.min.js. 

V('#lista .item').addClass('ativo');   // coleção encadeável
V.toast.success('Pronto');             // serviços

window.Voodoo é o mesmo objeto.

O que a expressão aceita

As expressões passam por um lexer, um parser Pratt e um interpretador de árvore próprios. Não existe eval, o que permite rodar sob Content Security Policy restritiva — e explica os limites.

Funciona: leitura e escrita de variáveis, acesso por ponto e por colchete, chamada de método, operadores aritméticos, de comparação e lógicos, ternário, encadeamento opcional (?.), coalescência (??), literais de objeto e de array, template string, funções de seta de uma expressão, e sequências separadas por ponto e vírgula.

Não funciona: function, new, blocos com chaves, if e laços, await, atribuição a globais.

Identificadores que não estão em nenhum escopo são procurados em uma lista fechada: 

Math  JSON  Date  Number  String  Boolean  Array  Object  Intl  RegExp  Promise
parseInt  parseFloat  isNaN  isFinite  encodeURIComponent  decodeURIComponent  console

Tudo fora dela devolve undefined, inclusive window, document, fetch, localStorage e o próprio V. Isso é proposital: um atributo vindo do banco de dados não consegue alcançar a API do navegador. Para liberar o que é seu: 

V.config.globals.formatarCPF = (v) => V.applyMask(v, 'cpf');
V.config.globals.APP = { versao: '2.1', ambiente: 'producao' };

Dois "once" diferentes

V.once é o barramento de eventos. O utilitário once, que executa uma função uma única vez, está no import direto: import { once } from 'voodoojs/utils'.
