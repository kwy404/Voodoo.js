Qualidade e migração

Perguntas frequentes

As dúvidas que mais aparecem, com a resposta curta. Sintomas de erro têm página própria em problemas comuns.

Geral

A Voodoo.js precisa de build?

Não. Você baixa um arquivo, aponta uma tag <script> e escreve HTML. Não existe compilador, bundler nem arquivo de configuração no caminho.

Qual arquivo eu escolho?

Comece pelo voodoo.min.js: ele traz reatividade, directives, componentes, HTTP, formulários, validação, máscaras, interface, arrastar e soltar, notificações, diálogos, som e armazenamento. Troque pelo voodoo.full.min.js no dia em que precisar de gráfico, animação com mola, roteador, idiomas, inspetor ou os 29 componentes prontos. E voodoo.core.min.js existe para páginas que só precisam de estado, renderização, eventos e requisições.

Por que a interpolação usa chave simples?

Porque é o que a maioria das pessoas tenta escrever primeiro. { nome } é a forma padrão; {{ nome }} também funciona, para quem vem do Vue e para textos que precisam de chaves literais em volta.

Onde os meus atributos v-* foram parar?

Eles são removidos do HTML depois de processados, de propósito, para deixar o DOM limpo no inspetor. O comportamento continua funcionando porque os valores ficam guardados no runtime. Para manter, V.config.cleanAttributes = false, ou data-keep-attributes na tag do script.

Meu CSS parou de funcionar

Provavelmente ele dependia de um seletor de atributo, como [v-tab] { ... }. Use classes: as directives de interface já aplicam as suas — v-tab, v-active, v-drawer-panel, v-dropzone e assim por diante.

Funciona com Content Security Policy restritiva?

Sim, sem unsafe-eval. Só o style-src precisa de 'unsafe-inline', por causa do CSS injetado, e isso pode ser dispensado com data-no-styles. A página de segurança tem as políticas prontas.

Quais navegadores são suportados?

Os builds têm alvo es2018 e usam Proxy, fetch, IntersectionObserver, MutationObserver e AbortController. Na prática, qualquer navegador atualizado dos últimos anos. Não há suporte a Internet Explorer, e nem haverá.

Funciona em Node?

Os módulos puros sim: reatividade, HTTP, utilitários e o parser não tocam no DOM. O que depende de DOM só roda no navegador. Não existe renderização no servidor.

A biblioteca tem dependências?

Nenhuma em tempo de execução. Em desenvolvimento existem tsup, typescript, vitest, jsdom e prettier.

Uso do dia a dia

Como faço algo assim que a página carrega?

<div v-data="{ dados: null }" v-init="carregar()"></div>

Ou V.ready(fn) em JavaScript, ou o evento voodoo:ready.

Como acesso um elemento?

<input v-ref="busca">
<button @click="$refs.busca.focus()">Focar</button>

Dentro de manipuladores, $el é o elemento que declarou a directive.

Como sei se uma requisição está em andamento?

Com v-resource, é recurso.loading. Em formulários, é $form.loading. Nas directives de verbo, use v-loading="#spinner" e v-disable-loading.

Elementos criados por JavaScript ganham directives?

Sim. Um MutationObserver inicializa o que aparece no DOM depois do carregamento. Se você desligou com data-no-observer, chame V.walk(elemento) à mão.

Como escrevo uma função com várias linhas em um atributo?

Não escreva. O parser aceita expressões, não blocos. Coloque a lógica em um método do v-data, de um componente ou do escopo raiz, e chame pelo nome.

Como faço debounce com um tempo diferente do padrão?

<input v-model.debounce="busca" v-debounce="600">
V.data({ buscar: V.debounce((t) => carregar(t), 600) });

Como mando o valor limpo da máscara para o servidor?

<input v-mask.unmask="cpf" v-model="form.cpf" v-cpf>

A tela mostra 123.456.789-01 e o estado guarda 12345678901.

Como valido no servidor e mostro o erro no campo certo?

Devolva 422 com { "errors": { "email": "Já cadastrado" } }. O v-submit distribui as mensagens para os campos pelo name, e as que não têm campo correspondente aparecem em um resumo no topo.

O v-sortable reordena o meu array?

Não. Ele move os elementos no DOM. Escute voodoo:sorted e reordene o array, ou salve a ordem no servidor — sem isso, a próxima renderização volta à ordem antiga.

Dá para usar junto com Bootstrap, Tailwind ou o meu CSS?

Sim. A Voodoo não impõe estilo. As directives de interface injetam apenas o mínimo, e você pode desligar com data-no-styles. Para o Tailwind, aponte as cores do tema para as variáveis --v-* e as duas coisas passam a andar juntas.

Dá para usar junto com jQuery, Alpine ou Vue?

Sim, todas usam o DOM padrão. Marque a região de outra biblioteca com v-ignore para que a Voodoo não toque nela.

Como faço testes?

O núcleo funciona em jsdom. O padrão do projeto é montar um trecho, percorrer e conferir:

document.body.innerHTML = '<div v-data="{ n: 0 }"><b v-text="n"></b></div>';
V.start();
await V.nextTick();
expect(document.querySelector('b').textContent).toBe('0');

V.flushSync() aplica tudo que está pendente sem esperar a microtask.

Projeto

Qual é a licença?

MIT.

Como reporto um bug?

Abra uma issue com um exemplo mínimo que reproduza o problema, de preferência um HTML de uma página só. Vulnerabilidades de segurança não vão em issue pública: veja como reportar.

Como peço um recurso novo?

Abra uma issue de proposta explicando o problema antes da solução. O que está fora do escopo hoje está listado no roadmap, em o que é a Voodoo.js.

Como contribuo com código?

npm install
npm test
npm run typecheck
npm run build
npm run size

O arquivo CONTRIBUTING.md do repositório tem o resto: padrão de commit, estrutura de pastas e o que a revisão espera.
