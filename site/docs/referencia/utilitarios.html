Referência

Utilitários

Funções que a própria biblioteca usa por dentro e publica em V. Todas existem também como importação direta, em voodoojs/utils, para quem monta o projeto com um bundler.

Identificadores e tempo

FunçãoDevolve
V.uuid()UUID v4. Usa crypto.randomUUID quando disponível, com dois planos B
V.uid(prefixo?)Identificador curto, útil para ids de elementos
V.sleep(ms)Promessa que resolve depois do tempo
V.parseDuration(valor, padrao?)Milissegundos a partir de 300, '300ms', '1.5s', '2m', '1h'
 
V.uid('campo-');           // 'campo-k3f9a2'
V.parseDuration('1.5s');   // 1500
V.parseDuration(null, 99); // 99

parseDuration aceita null porque a origem mais comum é um getAttribute que pode não existir.

Funções de ordem superior

debounce e throttle

const buscar = V.debounce(carregarProdutos, 300);
buscar('cane');
buscar('caneca');   // só esta executa
buscar.cancel();    // descarta a chamada pendente
buscar.flush();     // executa agora, sem esperar

const salvarAgora = V.debounce(salvar, 1000, true);  // borda de entrada

const acompanhar = V.throttle(medirRolagem, 100);
window.addEventListener('scroll', acompanhar, { passive: true });

once e memoize

const iniciar = V.once(() => criarConexao());
iniciar();
iniciar();  // devolve a mesma conexão

const calcular = V.memoize((a, b) => operacaoCara(a, b));
calcular.cache.clear();
const porId = V.memoize(buscar, (id) => String(id));  // chave própria
Cuidado com o nome

V.once no objeto global é o barramento de eventos (V.once('evento', handler)). O utilitário que executa uma função uma única vez está no import direto: import { once } from 'voodoojs/utils'.

Objetos e arrays

FunçãoO que faz
V.clone(valor)Cópia profunda. Usa structuredClone quando existir; entende Date, Map e Set
V.merge(alvo, ...fontes)Mescla em profundidade. Arrays são substituídos, não concatenados
V.groupBy(lista, chaveOuFn)Agrupa em um objeto
V.unique(lista, chaveOuFn?)Remove repetidos
V.chunk(lista, tamanho)Quebra em pedaços
V.sortBy(lista, chaveOuFn, direcao?)Ordena sem alterar o original
V.get(objeto, caminho, padrao?)Leitura de caminho aninhado, com segurança
V.set(objeto, caminho, valor)Escrita, criando os objetos do meio
V.random(min, max), V.sample(lista)Inteiro no intervalo, e item qualquer
 
V.merge({ a: { b: 1 } }, { a: { c: 2 } });  // { a: { b: 1, c: 2 } }
V.unique(pontos, (p) => p.x + ',' + p.y);
V.sortBy(produtos, 'preco', 'desc');
V.get(dados, 'lista.0.nome', 'sem nome');
V.set(form, 'itens.0.qtd', 2);

Dois detalhes que evitam surpresa: merge modifica o primeiro objeto — passe {} na frente quando quiser preservar. E sortBy compara textos com localeCompare e ordenação numérica, o que resolve item 2 antes de item 10; valores nulos vão para o fim.

Textos

V.slugify('Ação e Reação');        // 'acao-e-reacao'
V.slugify('Meu Post', '_');        // 'meu_post'
V.truncate('Um texto bem longo', 10);       // 'Um text...'
V.truncate('Um texto bem longo', 10, '…');  // 'Um texto…'
V.capitalize('voodoo');            // 'Voodoo'
V.titleCase('JAVASCRIPT feels');   // 'Javascript Feels'
V.escapeHtml('<b>oi</b>');         // '&lt;b&gt;oi&lt;/b&gt;'
V.stripTags('<b>oi</b>');          // 'oi'
stripTags não é sanitizador

escapeHtml é o caminho seguro para montar HTML na mão. stripTags remove tags de forma simples e não serve como defesa contra conteúdo hostil. A página de segurança explica a diferença.

Formatadores

Todos usam o locale e a moeda padrão, ajustáveis:

V.setFormatDefaults('pt-BR', 'BRL');

O bootstrap já configura isso a partir de V.config.locale e V.config.currency.

ChamadaResultado
V.formatCurrency(1234.5)R$ 1.234,50
V.formatCurrency(99, { currency: 'USD', locale: 'en-US' })$99.00
V.formatNumber(1234.5678)1.234,568
V.formatNumber(0.75, { style: 'percent' })75%
V.formatDate(new Date())29/08/2026
V.formatDate(data, 'long')29 de agosto de 2026
V.formatDate(data, 'DD/MM/YYYY HH:mm:ss')máscara textual
V.relativeTime(Date.now() - 300000)há 5 minutos
V.formatFileSize(1536)1.5 KB
V.formatPercent(0.256, 1)25,6%

formatDate aceita Date, timestamp ou texto ISO, e devolve texto vazio para uma data inválida. Os formatos nomeados são long, full, time e datetime; a máscara textual entende YYYY, YY, MM, DD, HH, mm e ss; e um objeto é repassado ao Intl.DateTimeFormat.

Ambiente

MembroO que é
V.isBrowserExiste DOM?
V.deviceGetters de toque, tamanho, movimento e tema
V.screenObjeto reativo com largura, altura e pontos de quebra
V.networkObjeto reativo com o estado da conexão
V.clipboardcopy e read

Dentro do HTML, os três últimos aparecem como $screen, $network, $device e $clipboard. Como screen e network são reativos, uma expressão que os lê se atualiza sozinha quando a janela muda de tamanho ou a conexão cai. 

<div v-data="{}">
  <p>Largura: { $screen.width }px</p>
  <p>É celular: { $screen.mobile }</p>
  <p>Online: { $network.online }</p>
  <p>Toque: { $device.touch }</p>
  <button @click="$clipboard.copy('PROMO10')">Copiar cupom</button>
</div>

Importando direto

import { debounce, formatCurrency, slugify, once } from 'voodoojs/utils';

Esse ponto de entrada não carrega o runtime de DOM, então ele serve inclusive em Node — é a forma de reaproveitar os formatadores no servidor sem arrastar a biblioteca inteira.
