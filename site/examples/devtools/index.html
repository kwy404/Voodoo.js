DevTools da Voodoo

Um atributo no <script> e o inspetor esta na pagina. Mexa nos controles abaixo e veja a reatividade acontecendo em tempo real.

✦
Procure o botao Voodoo no canto inferior direito. Clique nele para abrir o painel, ou use Ctrl+Shift+F2. Arraste o botao para onde preferir — a posicao fica salva. O painel destaca cada elemento reativo e pisca quando um efeito escreve nele.

Reatividade

Cada clique dispara um efeito que escreve em um unico no de texto.

{ contador } dobro: { contador * 2 }

Listas

O painel mostra um escopo por item, e so o item alterado pisca.

{ tarefa.texto }

Nenhuma tarefa.

Store global

Estado compartilhado, visivel na aba Stores do inspetor.

no carrinho: { $store.carrinho.itens.length }

Componente

Props, estado local e evento subindo para o pai.

ultimo valor emitido: { ultimo }

Rede

Requisicoes aparecem na aba Rede, com metodo, status e duracao.

carregando… { resultado }
