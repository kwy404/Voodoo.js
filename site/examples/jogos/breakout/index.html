O que esta demo mostra. O placar, as vidas, o nivel, a lista de power-ups, os menus e as telas de pausa e de fim de jogo sao HTML declarativo lendo o estado do componente. O loop do jogo nunca escreve no DOM: ele desenha no canvas e, quando alguma coisa que a interface exibe muda, apenas atribui a uma propriedade do componente. O recorde vai para o V.storage e todo o som sai sintetizado do V.sound, sem nenhum arquivo de audio.
