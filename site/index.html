No build step

                
The file you edit is the file the browser runs

                

                  JSX usually needs a toolchain between your editor and the page. Voodoo reads the JSX at
                  runtime, so there is nothing to install, configure or wait for. Open the file, even straight
                  from your disk, and the spell is cast.
                

              

              

                
                
              

            


            

              
              
            


            

              The honest cost: a compiler turns JSX into DOM calls ahead of time and Voodoo reads it at
              runtime, so a compiled framework wins on raw update speed and ships a smaller bundle. What you
              get back is a file you can open, edit and send to someone, with no node_modules anywhere in the
              story.
            

          

        


        
        

          

            

              

                
                
              

              

                
Directives

                
A grimoire of attributes

                

                  Behaviour is written where it belongs, on the element it changes. Once a directive is read,
                  its attribute leaves the document, so what the browser keeps is ordinary HTML.
                

                

                  95 directives
                  No eval, strict CSP friendly
                

              

            


            
    
              
  • 
                
    
                  
    v-data
    
                  
    Reactive state for an element and everything inside it.
    

    <div v-data="{ open: false }">
    
                
    
              
    • 
              
  • 
                
    
                  
    { expression }
    
                  
    Any expression, or JSX, straight into the markup.
    

    <p>Hello, { user.name }</p>
    
                
    
              
    • 
              
  • 
                
    
                  
    @event
    
                  
    Events, with modifiers such as prevent, outside and debounce.
    

    <form @submit.prevent="save()">
    
                
    
              
    • 
              
  • 
                
    
                  
    v-model
    
                  
    Two-way binding for inputs, selects, checkboxes and components.
    

    <input v-model.trim="email">
    
                
    
              
    • 
              
  • 
                
    
                  
    v-for
    
                  
    Keyed lists, so a reorder moves nodes instead of rebuilding them.
    

    <li v-for="t in todos" :key="t.id">
    
                
    
              
    • 
              
  • 
                
    
                  
    v-if
    
                  
    Conditionals with v-else-if and v-else, or v-show to keep the node.
    

    <p v-if="error">{ error }</p>
    
                
    
              
    • 
              
  • 
                
    
                  
    :attr
    
                  
    Bind any attribute, class or style to state.
    

    <a :href="url" :class="{ active }">
    
                
    
              
    • 
              
  • 
                
    
                  
    v-resource
    
                  
    An HTTP request with its data, loading and error state.
    

    <div v-resource="users: /api/users">
    
                
    
              
    • 
              
  • 
                
    
                  
    v-validate
    
                  
    Forms that validate, mask and submit themselves.
    

    <input name="email" v-required v-email>

Measured

                
Quick where it counts, honest where it is not

                

                  Seven implementations of the same 1,000 row list, all bundled for production, run back to back
                  against the same document. Median of 30 samples in milliseconds, lower is better. A framework
                  whose DOM differs from the hand-written baseline is excluded rather than timed.
                

                

                  

                    
Update 1 in 10

                    
4.69 ms

                    
ahead of hand-written vanilla, at 6.65

                  

                  

                    
Clear 1,000 rows

                    
30.14 ms

                    
level with Preact, Vue and React

                  

                

              

              

                
                

                  Read honestly: on create Voodoo is third of seven, and vanilla still builds the list twice as
                  fast. Solid and Preact update faster, with a compiler. Voodoo is also the largest bundle here,
                  so if size is your main constraint, Alpine and Preact are the honest recommendation.
